É o software que simula o funcionamento de um switch real para conectar as máquinas virtuais ao host. Funciona como intermédio das redes virtuais e físicas.

### Funcionamento:
Trabalha junto com o hypervisor entre o host "real" e o virtual conectando duas interfaces de forma lógica como se fossem interfaces físicas reais.

Cada máquina virtual possui uma interface virtual com endereço MAC único que se conecta ao Switch Virtual que simula o funcionamento de um Switch real e encapsula quadros vindos dessas interfaces. Quando o pacote chega da internet também passa pelo Bridge Virtual para ser enviado á VM de destino.
