### O que é VRF?
O uso de endereços privados é um dos métodos utilizados para preservar endereços públicos IPv4 além de facilitar o uso da rede em ambientes fechados. Agora pense em um cenário simples, como é possível que os roteadores de uma provedora possa se comunicar com roteadores de empresas clientes utilizando os mesmos endereços privados?

VRF é a tecnologia que permite a criação de uma tabela de roteamento virtual no roteador para que haja comunicação entre diferentes roteadores utilizando os mesmos endereços IP privados.

### Configuração

1. Cria a tabela de roteamento virtual.
``` 
ISP(config)#vrf definition TABELA_VRF
```
2. Use o comando **‘address-family <ipv4 | ipv6>’**  para escolher a versão do IP.
```
ISP(config-vrf)#address-family ipv4
ISP(config-vrf-af)#
```
3. Entre na configuracao da interface desejada e associe a tabela VRF.
```
ISP(config)#interface gigabitEthernet 0/1
ISP(config-if)#vrf forwarding TABELA_VRF
```
4. Configure o endereco na interface.
```
ISP(config-if)#ip address 192.168.1.1 255.255.255.0
```
5. Verificação da tabela de roteamento do VRF
```
ISP#sh ip route vrf TABELA_VRF
```
