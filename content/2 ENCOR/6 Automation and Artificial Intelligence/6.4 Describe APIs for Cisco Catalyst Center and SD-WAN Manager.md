A API do **Cisco Catalyst SD-WAN Manager** é uma **API REST (Representational State Transfer)** utilizada para controlar, configurar e monitorar os dispositivos Cisco em uma rede overlay.

A API desempenha um papel fundamental ao permitir que aplicações clientes utilizem os recursos oferecidos pelo Cisco Catalyst SD-WAN Manager.

### API do Cisco SD-WAN Manager na visão geral do sistema

Alguns dos casos de uso da API do Cisco Catalyst SD-WAN Manager incluem:

**Provisionamento:** Simplifique tarefas manuais por meio da automação. As APIs permitem o provisionamento automatizado de redes overlay do Cisco Catalyst SD-WAN, eliminando a necessidade de administradores de rede configurarem manualmente roteadores, protocolos de roteamento, políticas de segurança e outros recursos do SD-WAN. As organizações podem utilizar plataformas de provisionamento ou ferramentas de automação, estabelecendo a base para o conceito de **Network as Code**.

**Visibilidade da rede:** As APIs aumentam a visibilidade da rede ao permitir a integração com ferramentas de monitoramento para coletar e analisar dados de desempenho da infraestrutura. Elas fornecem informações sobre o tráfego da rede, o estado dos dispositivos e possíveis problemas, possibilitando uma gestão proativa e uma solução de problemas mais eficiente.

**Integração com ferramentas de terceiros:** As APIs facilitam a integração com soluções externas de gerenciamento e monitoramento de redes, oferecendo uma visão mais abrangente do ambiente de rede.

**Network as Code:** Utiliza as APIs do Cisco Catalyst SD-WAN Manager para automatizar a configuração e o gerenciamento da rede, tratando a infraestrutura como um recurso programável. Essa abordagem permite implantações mais rápidas, configurações consistentes e adaptação ágil às mudanças, aumentando a eficiência operacional e reduzindo a ocorrência de erros.
