Esse tópico requer que você saiba identificar diferentes arquiteturas de redes e seus principais conceitos.
### 2-tier 
A arquitetura 2 tier consistem em dois layers
- Layer de acesso: Consistem em todas as LANs conectadas aos access switches que garantirão acesso aos endpoints.
- Layer de distribuicão: Este layer possui um switch multi-layer que conecta todos os switches de acesso.

### 3-tier
Empresas maiores podem optar por usar uma arquitetura 3-tier que entrega mais garantia de acesso e confiabilidade. Essa arquitetura consistem em 3 Layers.
-  Layer de acesso: Consistem em todas as LANs conectadas aos access switches que garantirão acesso aos endpoints.
- Layer de distribuicão: Este layer possui um switch multi-layer que conecta todos os switches de acesso.
- Layer Core: Para gerenciar o tráfego de forma rápida, são adicionados +2 Switches Core que são o backbone da estrutura.

Nota-se que o ideal para as duas arquiteturas descritas anteriormente é que possuam dois switches em cada layer conectados entre si para que a rede não dependa de apenas um ponto de failover.
### Cloud
Computação em Nuvem é um termo coloquial para disponibilidade sob demanda de recursos computacionais, especialmente armazenamento de dados.

IaaS - Infrastructure as a Service:
Alocação de recursos para instalação do sistema próprio do cliente:

PaaS - Platform as a Service:
Alocação de plataforma para uso do cliente em servidores da empresa provedora

SaaS - Software as a Service:
Serviços de software alocados na empresa provedora que podem ser acessados pelo cliente principalmente via web-browser

### Fabric
Refere-se á arquiteturas onde os equipamentos se conectam uns nos outros para atingir um objetivo definido pela empresa. Alguns exemplos são:

- Leaf-Spine
- Arquitetura MESH
- FEz
- Software Defined Networking (SDN)
