### Configuração

#### NAT estática

1. Configure a interface no AS Inside Global
```ip nat outside```

2. Configure a interface no AS Inside Local
```ip nat inside```

3. Por último, habilite o Static Nat usando o comando: 
```
Router(config)#ip nat inside source 
static <outside-global-ip> <outside-local-ip>
```

Exemplo:
```
R1(config)#int f0/0
R1(config-if)#ip nat outside
R1(config-if)#exit
R1(config)#int f1/0
R1(config-if)#ip nat inside
R1(config-if)#exit
R1(config)#ip nat outside source static 30.1.1.1 192.168.1.2
```

Para verificar as traduções NAT 
```R1#show ip nat translations```

#### NAT dinâmica

1. Configure a interface no AS Inside Global
```ip nat outside```

2. Configure a interface no AS Inside Local
 ```ip nat inside```

3. Crie uma pool de endereços IP's globais: 
```
Router(config)#ip nat pool <pool-name> 
<starting-IP> <ending-IP> prefix-length <prefix-length>
```

4. Crie uma access list para permitir uma rede específica de endereços IP: 
```
Router(config)#access-list <acl-number> 
permit <source-ip-network> <wildcard-mask>
```

5. Por último, habilite o Dynamic NAT usando o commando:
```
Router(config)#ip nat inside source 
list <acl-number> pool <pool-name>
```

#### PAT (Port Address Translation / NAT Overload)

1. Configure a interface conectada à Internet como **Outside**:

```
ip nat outside
```

2. Configure a interface da rede interna como **Inside**:

```
ip nat inside
```

3. Crie uma ACL para identificar a rede interna:

```
Router(config)#access-list <acl-number> permit <source-network> <wildcard-mask>
```

4. Habilite o PAT utilizando o endereço IP da interface de saída:

```
Router(config)#ip nat inside source list <acl-number> interface <outside-interface> overload
```
