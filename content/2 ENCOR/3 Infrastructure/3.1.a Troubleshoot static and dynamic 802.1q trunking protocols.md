O **802.1Q** é o padrão utilizado para transportar **múltiplas VLANs por um único link físico**, identificando cada quadro Ethernet com uma **tag VLAN**.

### Tipos de trunk

- **Trunk estático:** Configurado manualmente nas portas do switch. É mais previsível e confiável.
- **Trunk dinâmico:** Utiliza o **DTP (Dynamic Trunking Protocol)** para negociar automaticamente a criação do trunk entre switches.

### Problemas comuns

- **Native VLAN mismatch:** A VLAN nativa é diferente nas duas extremidades do trunk, causando encaminhamento incorreto de tráfego sem tag.
- **VLANs não permitidas ou configuradas incorretamente:** Pacotes não chegam ao destino.
- **Problemas com DTP:** Configurações incompatíveis impedem a negociação do trunk.
- **Port security ou configurações incorretas:** Podem impedir o funcionamento do trunk.

### Troubleshooting

- Verificar a configuração dos trunks com:
    - `show interfaces trunk`
    - `show running-config`
- Confirmar que:
    - As VLANs permitidas são as mesmas nos dois lados.
    - A **Native VLAN** é igual em ambas as pontas.
    - As configurações de DTP são compatíveis (`show dtp interface`).
- Quando necessário, configurar o trunk como **`nonegotiate`** para desabilitar a negociação automática.

### Boas práticas

- Verificar as alterações após a configuração.
- Utilizar ferramentas como **Wireshark** para analisar o tráfego.
- Manter documentação atualizada das VLANs e portas trunk.
- Monitorar a interação com o **Spanning Tree Protocol (STP)** para evitar loops.
