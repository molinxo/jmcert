Os protocolos **NTP** e **PTP** sincronizam o relógio dos dispositivos da rede, garantindo consistência em logs, autenticação, monitoramento e aplicações sensíveis ao tempo.

---

# NTP (Network Time Protocol)

O **NTP** sincroniza o relógio dos dispositivos utilizando servidores de tempo.

### Características

- Utiliza **UDP porta 123**.
- Sincronização em **milissegundos**.
- Estrutura hierárquica por **Stratum**.
- Muito utilizado em roteadores, switches e servidores.

**Stratum**

- **Stratum 0:** Relógio de referência (GPS, relógio atômico).
- **Stratum 1:** Conectado diretamente ao Stratum 0.
- **Stratum 2+**: Sincronizam com níveis superiores.

### Configuração

```
ntp server 192.168.1.10
```

Opcionalmente, definir a interface de origem:

```
ntp source Loopback0
```

### Verificação

```
show ntp associations
show ntp status
show clock
```

# PTP (Precision Time Protocol)

O **PTP (IEEE 1588)** fornece sincronização de alta precisão para aplicações que exigem tempo extremamente preciso.

### Características

- Precisão em **microssegundos ou nanossegundos**.
- Utilizado em:
    - Data Centers
    - Telecom (5G)
    - Automação industrial
    - Redes financeiras

### Componentes

- **Grandmaster Clock:** Fonte principal de tempo.
- **Boundary Clock:** Redistribui o tempo.
- **Transparent Clock:** Corrige o atraso dos switches.
- **Ordinary Clock:** Cliente PTP.

### Configuração (Cisco)

```
ptp mode boundary
```

ou

```
interface GigabitEthernet0/0
 ptp enable
```

### Verificação

```
show ptp clock
show ptp port
```
