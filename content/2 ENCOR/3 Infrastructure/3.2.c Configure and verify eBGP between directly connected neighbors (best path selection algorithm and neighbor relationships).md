O **eBGP (External Border Gateway Protocol)** é utilizado para trocar rotas entre **Sistemas Autônomos (ASs) diferentes**. Os vizinhos eBGP devem estar **diretamente conectados** (TTL padrão = 1).

---

## Configuração básica

### Roteador R1 (AS 65001)

```
router bgp 65001
 bgp router-id 1.1.1.1
 neighbor 192.168.12.2 remote-as 65002
 network 10.1.1.0 mask 255.255.255.0
```

### Roteador R2 (AS 65002)

```
router bgp 65002
 bgp router-id 2.2.2.2
 neighbor 192.168.12.1 remote-as 65001
 network 10.2.2.0 mask 255.255.255.0
```

---

## Relação de Vizinhança (Neighbor Relationship)

Antes de trocar rotas, os roteadores estabelecem uma sessão BGP utilizando **TCP porta 179**.

**Estados da sessão BGP:**

```
Idle
 ↓
Connect
 ↓
Active
 ↓
OpenSent
 ↓
OpenConfirm
 ↓
Established
```

Somente no estado **Established** ocorre a troca de rotas.

**Requisitos para formar vizinhança:**

- AS remoto correto (`remote-as`).
- Conectividade IP entre os vizinhos.
- TCP porta **179** liberada.
- Endereço IP do vizinho correto.

---

## Best Path Selection (Seleção do Melhor Caminho)

Quando existem múltiplas rotas para o mesmo destino, o BGP escolhe a melhor seguindo, em ordem simplificada:

1. **Weight** (maior) _(Cisco)_
2. **Local Preference** (maior)
3. Rota originada localmente.
4. **AS Path** (menor)
5. **Origin** (IGP < EGP < Incomplete)
6. **MED** (menor)
7. Preferir **eBGP** em vez de iBGP.
8. Menor custo IGP até o next-hop.
9. Menor Router ID.
