Em redes empresariais é importante escolher corretamente os protocolos de roteamento para o bom funcionamento da rede. Hoje em dia existe uma vasta gama de opcoes de protocolos mas dois deles são comumente comparados estes são **OSPF** e **EIGRP**. Ambos são considerados Interior Gateway Protocol.

### EIGRP (Enhanced Interior Gateway Routing Protocol)

O **EIGRP** é um protocolo de roteamento **híbrido**, desenvolvido pela **Cisco**. É considerado um **Advanced Distance Vector** pois combina características de **Distance Vector** e **Link-State**. Utiliza o algoritmo **DUAL**, proporcionando convergência muito rápida e rotas de backup.

**Características:**

- Proprietário da Cisco (há suporte limitado por outros fabricantes).
- Algoritmo **DUAL**.
- Baixo uso de CPU e memória.
- Suporta balanceamento de carga com custos diferentes (Unequal Cost Load Balancing).
- Seleciona a rota com a menor métrica composta (**largura de banda** + **delay**)
- Atualizações parciais, tabela de topologia, **Successor** e **Feasible Successor**
- Não utiliza áreas.

**Distância Administrativa (AD):**

- **90** (rotas internas)
- **170** (rotas externas)

---

### OSPF (Open Shortest Path First)

O **OSPF** é um protocolo de roteamento **Link-State** e padrão aberto (**IETF**). Utiliza o algoritmo **Dijkstra (SPF)** para calcular o menor caminho entre os roteadores.

**Características:**

- Padrão aberto (multivendor).
- Algoritmo **Dijkstra (SPF)**.
- Maior consumo de CPU e memória.
- Balanceamento de carga apenas entre caminhos de mesmo custo (Equal Cost).
- Seleciona a rota com o menor **Cost** (baseado na largura de banda)
- Troca de **LSAs**, **LSDB** compartilhada e recálculo da árvore **SPF**
- Utiliza áreas hierárquicas (Backbone Area 0, Stub, Totally Stubby*, NSSA e Totally NSSA*)

**Distância Administrativa (AD):**

- **110**

---

| Característica | EIGRP                      | OSPF                 |
| -------------- | -------------------------- | -------------------- |
| Tipo           | Híbrido                    | Link-State           |
| Padrão         | Cisco                      | IETF (aberto)        |
| Algoritmo      | DUAL                       | Dijkstra (SPF)       |
| Convergência   | Muito rápida               | Rápida               |
| Métrica        | Banda + Delay              | Cost (banda)         |
| Balanceamento  | Custos iguais e diferentes | Apenas custos iguais |
| AD             | 90 / 170                   | 110                  |
| Configuração   | Simples                    | Mais complexa        |
