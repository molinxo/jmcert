# HSRP (Hot Standby Router Protocol)

- Protocolo **proprietário da Cisco**.
- Utiliza um **IP virtual** compartilhado entre dois ou mais roteadores.
- Apenas o **Active Router** encaminha tráfego.
- O **Standby Router** assume automaticamente em caso de falha.

### Configuração

#### R1 (Active)

```
interface GigabitEthernet0/0
 ip address 192.168.1.2 255.255.255.0
 standby 1 ip 192.168.1.1
 standby 1 priority 110
 standby 1 preempt
```

#### R2 (Standby)

```
interface GigabitEthernet0/0
 ip address 192.168.1.3 255.255.255.0
 standby 1 ip 192.168.1.1
 standby 1 priority 100
 standby 1 preempt
```

### Verificação

```
show standby
show standby brief
```

# VRRP (Virtual Router Redundancy Protocol)

- **Padrão aberto (RFC)**.
- Funciona de forma semelhante ao HSRP.
- O roteador com maior prioridade torna-se o **Master**.
- O IP virtual normalmente pode ser o mesmo do gateway.

### Configuração

#### R1 (Master)

```
interface GigabitEthernet0/0
 ip address 192.168.1.2 255.255.255.0
 vrrp 1 ip 192.168.1.1
 vrrp 1 priority 110
 vrrp 1 preempt
```

#### R2 (Backup)

```
interface GigabitEthernet0/0
 ip address 192.168.1.3 255.255.255.0
 vrrp 1 ip 192.168.1.1
 vrrp 1 priority 100
 vrrp 1 preempt
```

### Verificação

```
show vrrp
show vrrp brief
```
