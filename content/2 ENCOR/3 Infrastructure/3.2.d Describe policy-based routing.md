O **Policy-Based Routing (PBR)** permite encaminhar pacotes com base em **políticas definidas pelo administrador**, em vez de utilizar apenas a tabela de roteamento.

Enquanto o roteamento tradicional escolhe o caminho com base no **endereço IP de destino.** o PBR pode tomar decisões considerando outros critérios.

## Critérios utilizados

- Endereço IP de origem.
- Endereço IP de destino.
- ACLs.
- Protocolo.
- Interfaces de entrada.
- Outros campos do pacote.

## Funcionamento

1. Cria-se uma **ACL** para identificar o tráfego.
2. Cria-se um **Route Map** com a ação desejada.
3. Aplica-se o Route Map na interface de entrada.

## Configuração básica

```
access-list 10 permit 192.168.10.0 0.0.0.255

route-map PBR permit 10
 match ip address 10
 set ip next-hop 192.168.20.1

interface GigabitEthernet0/0
 ip policy route-map PBR
```

## Verificação

```
show route-map
show ip policy
show ip interface
show access-lists
```

## Casos de uso

- Engenharia de tráfego.
- Direcionar determinados usuários por um link específico.
- Balanceamento de carga baseado em políticas.
- Redundância.
- Separação de tráfego (voz, dados, aplicações).
