O Spanning Tree Protocol (STP) evita loops de Camada 2, bloqueando links redundantes e mantendo apenas um caminho ativo entre switches.

### RSTP (Rapid Spanning Tree Protocol – IEEE 802.1w)
- Evolução do STP tradicional.
- Convergência rápida (1 a 10 segundos).
- Utiliza novos papéis e estados de portas para reduzir o tempo de recuperação após falhas.

**Configuração**
```
spanning-tree mode rapid-pvst
``` 
**Verificação**
```
show spanning-tree
show spanning-tree summary
show spanning-tree interface
```

### MST (Multiple Spanning Tree – IEEE 802.1s)
- Agrupa várias VLANs em uma única instância STP.
- Reduz o processamento em switches.
- Permite balanceamento de carga entre VLANs.
**Configuração**
```
spanning-tree mode mst

spanning-tree mst configuration
 name CAMPUS
 revision 1
 instance 1 vlan 10,20
 instance 2 vlan 30,40
 exit 
```
 
**Verificação**

```
show spanning-tree mst
show spanning-tree mst configuration
show spanning-tree summary
```

### Root Guard
- Impede que um switch não autorizado se torne o Root Bridge.
- Coloca a porta em estado root-inconsistent ao receber uma BPDU superior.
**Configuração**
```
interface GigabitEthernet1/0/1
 spanning-tree guard root
```
**Verificação**
```
show spanning-tree inconsistentports
show spanning-tree interface GigabitEthernet1/0/1 detail
```

### BPDU Guard
- Protege portas PortFast.
- Se receber uma BPDU, coloca a interface em err-disabled.
**Configuração por interface**
```
interface GigabitEthernet1/0/10
 spanning-tree portfast
 spanning-tree bpduguard enable 
```

**Configuração global (recomendada)**
```
spanning-tree portfast default
spanning-tree portfast bpduguard default
```

**Verificação**
```
show spanning-tree summary
show spanning-tree interface GigabitEthernet1/0/10 detail
show errdisable recovery
```

show spanning-tree interface

show interfaces status
