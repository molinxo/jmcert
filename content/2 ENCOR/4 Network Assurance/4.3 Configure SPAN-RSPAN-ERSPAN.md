O **SPAN (Switch Port Analyzer)** é um recurso dos switches Cisco que **copia o tráfego** de uma porta, VLAN ou EtherChannel para outra porta, permitindo a captura e análise dos pacotes por ferramentas como o **Wireshark**.
### Tipos de SPAN

- **Local SPAN:** Copia o tráfego para outra porta no **mesmo switch**.
- **RSPAN (Remote SPAN):** Copia o tráfego entre **switches** através de uma VLAN dedicada.
- **ERSPAN (Encapsulated Remote SPAN):** Encapsula o tráfego em **IP (Camada 3)** para monitoramento remoto.

O **RSPAN (Remote SPAN)** permite espelhar o tráfego de uma porta em um **switch remoto**, enviando a cópia dos pacotes por uma **VLAN exclusiva de RSPAN** através de links trunk.

O **ERSPAN** é uma evolução do RSPAN que permite espelhar tráfego entre dispositivos em **redes diferentes (Layer 3)**. O tráfego espelhado é encapsulado em pacotes IP e enviado pela rede até um analisador remoto.
### Fontes de captura

O tráfego pode ser espelhado a partir de:

- Interface física.
- EtherChannel/Port-Channel.
- VLAN.
- Porta Trunk.

É possível capturar:

- **RX** (recebido).
- **TX** (transmitido).
- **Both** (ambos - padrão).

### Configuração básica

#### Local:

Configurar a sessão:
``` 
monitor session <session-id> source {interface <interface-id> | vlan <vlan-id>} [rx | tx | both]
```

Pode ser configurado em uma porta Trunk, porém o tráfego deverá ser filtrado com o seguinte comando:
```
monitor session <session-id> filter vlan <vlan-range>
```

Atribuicao da interface na sessão:
```
Switch1(config)#monitor session 1 source interface 
Switch1(config)#monitor session 1 destination interface 
```

Na porta de destino deverá ser configurado:
```
monitor session <session-id> destination interface <interface-id> [encapsulation {dot1q [ingress {dot1q vlan <vlan-id> | untagged vlan <vlan-id> | vlan <vlan-id>}| replicate [ingress {dot1q vlan <vlan-id> | untagged vlan <vlan-id>]}} | ingress]
```

Normalmente tags VLAN não são encapsuladas pelo NetFlow para preservar as tags 802.1Q use o comando:
```
monitor session 1 destination interface GigabitEthernet0/1 encapsulation replicate
```

#### RSPAN

Criar a VLAN RSPAN em todos os switches:
```
vlan 50
 remote-span
```

Configurar os links entre os switches como trunk:
```
interface GigabitEthernet0/0
 switchport trunk encapsulation dot1q
 switchport mode trunk
```

Configurar o switch de origem:
```
monitor session 1 source interface GigabitEthernet0/1
monitor session 1 destination remote vlan 50
```

Configurar o switch de destino:
```
monitor session 1 source remote vlan 50
monitor session 1 destination interface GigabitEthernet0/1
```

Verificação
```
show monitor session
show monitor session remote
```

#### ERSPAN

Configurar a origem (ERSPAN Source)
```
monitor session 1 type erspan-source
 source interface GigabitEthernet0/0/1 rx
 destination
  erspan-id 10
  ip address 172.16.30.254
  origin ip address 172.16.20.10
 no shutdown
```

Configurar o destino (ERSPAN Destination)
```
monitor session 1 type erspan-destination
 destination interface GigabitEthernet0/0/1
 source
  erspan-id 10
  ip address 172.16.30.254
 no shutdown
```

Verificação
```
show monitor session
show monitor session erspan-source session
```

### Configuração
#### Local Span
###### Interface as source

| Command                                                                                      | Description                                                                             |
| -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| _(config)#monitor session 1 source interface fastEthernet 0/4_                               | trunk port, Both Ingress and egress traffic will be forwarded                           |
| _(config)#monitor session 1 source interface fastEthernet 0/10 rx_                           | Only ingress traffic will be forwarded                                                  |
| _(config)#monitor session 1 source interface fastEthernet 0/11 tx_                           | Only egress traffic will be forwarded                                                   |
| _(config)#monitor session 1 filter vlan 1 - 5 , 20 , 99_                                     | Filter / remove VLANs 1 - 5, 20 & 99 from trunk port for SPAN.                          |
| _(config)#monitor session 1 destination interface fastEthernet 0/20 encapsulation replicate_ | SPAN destination port & enables L2 protocol traffic to be forwarded to SPAN destination |
###### VLAN as source

| Command                                                             | Description                                                  |
| ------------------------------------------------------------------- | ------------------------------------------------------------ |
| _(config)#monitor session 2 source vlan 50 rx_                      | Only ingress traffic into ports in VLAN 50 will be forwarded |
| _(config)#monitor session 2 source vlan 80 tx_                      | Only egress traffic from ports in VLAN 80will be forwarded   |
| _(config)#monitor session 2 destination interface fastEthernet 0/5_ | SPAN destination.                                            |
###### Show command

| Command                                   | Description          |
| ----------------------------------------- | -------------------- |
| _# show monitor session "session number"_ | show monitor session |
#### Remote SPAN

###### On Source Switch

| Command                                                         | Description                       |
| --------------------------------------------------------------- | --------------------------------- |
| _(config)# vlan 101_                                            | configure VLAN                    |
| _(config-vlan)#remote span_                                     | Define VLAN as RSPAN VLAN         |
| _(config)#monitor session 1 source interface fastEthernet 0/10_ | Configure SPAN source both TX/RX. |
| _(config)#monitor session 1 destination remote vlan 101_        | configure RSPAN destination       |
###### On Intermediate Switch

| Command                     | Description               |
| --------------------------- | ------------------------- |
| _(config)# vlan 101_        | configure VLAN            |
| _(config-vlan)#remote span_ | Define VLAN as RSPAN VLAN |
###### On Destination Switch

| Command                                                             | Description                     |
| ------------------------------------------------------------------- | ------------------------------- |
| _(config)# vlan 101_                                                | Configure VLAN                  |
| _(config-vlan)#remote span_                                         | Define VLAN as RSPAN VLAN       |
| _(config)#monitor session 1 source remote vlan 101_                 | define source as RSPAN VLAN 101 |
| _(config)#monitor session 2 destination interface fastEthernet 0/2_ | RSPAN destination interface     |
###### Show command
| Command                                   | Description                 |
| ----------------------------------------- | --------------------------- |
| _# show monitor session "session number"_ | show monitor session        |
| _# show vlan remote-span_                 | Displays RSPAN VLAN details |

#### Encapsulated Remote SPAN
###### On Source switch/router

| Command                                                       | Description                                |
| ------------------------------------------------------------- | ------------------------------------------ |
| _(config)# monitor session 3 type erspan-source_              | define as ERSPAN source session            |
| _(config-mon-erspan-src)# description --This is Source Box--_ | Session description, Up to 240 characters. |
| _(config-mon-erspan-src)# source interface gig 4/1_           | define source interface ( RX/TX/both)      |
| _(config-mon-erspan-src)# no shutdown_                        | Activates ERSPAN source session            |
| _(config-mon-erspan-src)# destination_                        | source session destination config mode     |
| _(config-mon-erspan-src-dst)# ip address 10.1.1.1_            | define ERSPAN destination IP               |
| _(config-mon-erspan-src-dst)# origin ip address 20.1.1.1_     | IP used as source of the ERSPAN traffic.   |
| _(config-mon-erspan-src-dst)# erspan-id 101_                  | ID used to identify the ERSPAN traffic     |
###### On destination switch/router
| Command                                                        | Description                                |
| -------------------------------------------------------------- | ------------------------------------------ |
| _(config)# monitor session 5 type erspan-destination_          | define as ERSPAN destination session       |
| _(config-erspan-dst)# description --This is Destination Box--_ | Session description, Up to 240 characters. |
| _(config-erspan-dst)# destination interface gig 2/1_           | define destination interface               |
| _(config-erspan-dst)# no shutdown_                             | Activates ERSPAN destination session       |
| _(config-erspan-dst)# source_                                  | destination session source config mode     |
| _(config-erspan-dst-src)# ip address 10.1.1.1_                 | Source IP address configured on router.    |
| _(config-erspan-dst-src)# erspan-id 101_                       | ID should be same as configured in source  |
