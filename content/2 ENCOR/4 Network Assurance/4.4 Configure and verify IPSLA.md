O **IP SLA (IP Service Level Agreements)** é uma tecnologia da Cisco utilizada para monitorar continuamente o desempenho da rede e de aplicações. Ele funciona enviando sondas (probes) para um destino e medindo diversos parâmetros da comunicação, permitindo verificar a qualidade dos links e automatizar decisões de roteamento.

### Principais métricas monitoradas

- Latência (Round Trip Time - RTT)
- Jitter
- Perda de pacotes
- Disponibilidade do caminho
- Disponibilidade de aplicações (HTTP, FTP, DNS, entre outras)

Essas informações são utilizadas para validar SLAs, monitorar links WAN, verificar a qualidade da rede e implementar mecanismos de alta disponibilidade.
### Funcionamento

O IP SLA gera tráfego semelhante ao de aplicações reais entre um roteador de origem e um destino. A partir das respostas obtidas, o roteador calcula estatísticas como tempo de resposta, sucesso ou falha das operações e disponibilidade do serviço monitorado.

### Configuração do IP SLA

A configuração básica segue quatro etapas:

#### 1. Criar uma operação IP SLA

Define o identificador da operação.

```
ip sla <ID>
```

#### 2. Definir o tipo de teste

Os testes mais comuns são:

**ICMP Echo (Ping)**

```
icmp-echo <DESTINO> source-interface <INTERFACE>
```

Utilizado para verificar a conectividade e medir o RTT.

**HTTP GET**

```
http get http://<SERVIDOR>
```

Utilizado para verificar a disponibilidade e o tempo de resposta de uma aplicação HTTP.

#### 3. Definir a frequência

Especifica o intervalo entre as sondas.

```
frequency <segundos>
```

Exemplos:

- 5 segundos para monitoramento de links
- 60 segundos para monitoramento HTTP

#### 4. Agendar a execução

Sem o agendamento, a operação não é executada.

```
ip sla schedule <ID> start-time now life forever
```

O comando inicia imediatamente a operação e a mantém ativa permanentemente.

### Verificação do IP SLA

#### Verificar a configuração

```
show ip sla configuration
```

Exibe informações como:

- Tipo de operação
- Destino
- Interface de origem
- Frequência
- Timeout
- Estado da operação
- Tempo de vida
- Agendamento da sonda

#### Verificar estatísticas

```
show ip sla statistics
```

ou

```
show ip sla statistics <ID>
```

Mostra informações como:

- RTT (Round Trip Time)
- Código de retorno (OK, Timeout, etc.)
- Número de sucessos
- Número de falhas
- Tempo de vida da operação

Em operações HTTP também são exibidos:

- RTT da conexão TCP
- RTT da transação HTTP
- RTT de resolução DNS (quando aplicável)

### Integração com Object Tracking

O IP SLA pode ser integrado ao recurso **Object Tracking**, permitindo que o estado da sonda seja utilizado por outros recursos do IOS.

Configuração básica:

```
track 1 ip sla 10 reachability
```

O objeto acompanha a acessibilidade da operação IP SLA e pode ser utilizado por rotas estáticas, HSRP e outros mecanismos de redundância.

### Aplicação em Rotas Estáticas

Uma rota pode ser associada ao estado do Track:

```
ip route <rede> <máscara> <next-hop> track 1
```

Se o IP SLA detectar falha no destino monitorado, o Track muda para **Down**, removendo automaticamente a rota da tabela de roteamento. Caso exista uma rota secundária (rota flutuante), ela passa a ser utilizada. Quando a conectividade é restabelecida, a rota principal é reinstalada automaticamente.
