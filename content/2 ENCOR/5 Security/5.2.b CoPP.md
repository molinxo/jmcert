**Control Plane Policy** é um dos mecanismos usados para defesa do **Control Plane** contra ataques. 

Para defender o Control Plane de ataques existem dois métodos. O primeiro é usando os próprios mecanismos de defesa de cada protocolo usado no Control Plane e a outra forma é utilizando Policies, em outras palavras, utilizando **Control Plane Policy** 

CoPP nos permite policiar o tráfego que chega ao control plane, define classificacao, queue mapping e queue shaping para os pacotes do control plane.

O **Control Plane Policing (CoPP)** utiliza uma configuração do **Plano de Controle (Control Plane)** por meio do módulo de **QoS (Quality of Service)** da **Classe de Serviço (CoS)**. Em outras palavras, é utilizada uma configuração dedicada através da **QoS CLI (MQC - Modular QoS CLI)** para filtrar e limitar o tráfego destinado ao Plano de Controle. Essa política é independente e pode ser utilizada no dispositivo para filtragem ou outras atividades de policiamento. Ao proteger o Plano de Controle, o **CoPP** garante a estabilidade do roteamento, a alcançabilidade da rede e a entrega de pacotes.

Existem quatro processos principais no CoPP:

- **Classificação (Classification)**
- **Mapeamento de Filas (Queue Mapping)**
- **Escalonamento (Scheduling)**
- **Modelagem de Filas (Queue Shaping)**

### Configuração

Habilitar o MLS QoS.
```Router(config)# mls qos```

Definir ACLs.
```Router(config)# ip access-list extended access-list-name```

Na config de ACLs configure as regras.
```
Router(config-ext-nacl)# {permit | deny} protocol source source-wildcard destination destination-wildcard [precedence precedence] [tos tos] [established] [log | log-input] [time-range time-range-name] [fragments]
```

Definir classificacao dos pacotes.
```
Router(config)# class-map traffic-class-name

Router(config-cmap)# match {ip precedence} | {ip dscp} | access-group
```

Definir Service Policy Map
```
Router(config)# policy-map service-policy-name

Router(config-pmap)# class traffic-class-name
```

```
Router(config-pmap-c)# police {bits-per-second [normal-burst-bytes] [maximum-burst-bytes] [pir peak-rate-bps]} | [conform-action action] [exceed-action action] [violate-action action]
```

Control Plane Config Mode
```
Router(config)# control-plane
```

Aplicando Policy QoS
```
Router(config-cp)# service-policy input service-policy-name
```
