**Local User Database** é um set de usuários e senhas armazenados em um equipamento de rede. Oferece autenticacao apropriada enquanto o AAA não está disponível.

```
conf#username
```

### Tipos de Senha e Criptografia

#### TYPE 9 - **SCRYPT**

> **Recommended**, default when using the **secret** parameter.

```
conf# username foo privilege n algorithm-type scrypt secret pass
```
#### TYPE 8 - **PBKDF2-SHA-256**

> Password Based Key Derivation Function 2; **recommended**.

```
conf# username foo privilege n algorithm-type sha256 secret pass
```
#### TYPE 6 - **AES-128**

> Recommended, **REVERSIBLE** (knowing pass-encrypt key), requires additional configuration:

```
conf# password encryption aes
conf# key config-key password-encrypt key
conf# username foo priv n password pass
```

#### TYPE 5 - **MD5**

> Better than Type 0 or Type 7, but practical attacks exist; **no longer recommended**.

> **Deprecated in IOS-XE.**

```
conf# username foo privilege n secret 5 pass <xxxx>
```

#### TYPE 7 - **VIGENERE**

> Easy to crack; better than nothing, but **not recommended**.

> Encrypts Type 0 passwords, producing an encrypted Type 7 password.

```
conf# service password-encryption
```

#### TYPE 0 - **CLEAR TEXT**

> Not recommended at all. Avoid using it.

```
conf# username foo privilege n password pass
```

### Níveis de Privilégios

Os equipamentos possuem 15 níveis hierárquicos sendo 0-1 os mais básicos e 15 sendo o nível máximo possuindo todas as autorizacoes. os níveis 2-14 são os níveis customizaveis. Os níveis 0-1 também são customizáveis mas não é recomendado. 

É necessário uma senha para subir de nível mas não requer senha para descer.

- Atribuicao de nível a usuário
```conf# username usr privilege n```

- Atribuicao de privilegio á uma line
```conf# line xxx```
```line# privilege level n``` 

- Movimentacao entre niveis
```enable n```

- Para comandos operacionais:
```privilege EXEC```

- Para comandos de configuracao:
```privilege CONFIGURE```
```privilege <feature name>```

- Para garantir que permissões acessem a running config:
```file privilege <n>```


Configure os comandos menos perigosos e estruturais nos níveis mais baixos e os comandos mais impactantes nos níveis mais altos

Níveis mais baixos são pensados para usuários menos experientes e o mais altos para usuários mais experientes.

### RBRAC

Role Based Access Control é um Local Authorization Database em que alguns comandos operacionais e de configuracao são organizados em uma base por **View**. Como todas as outras ferramentas de autorizacao esta decide "quem pode executar o que".

Garante autorizacao mesmo que o servidor AAA não esteja disponível

**View** é uma lista de comandos que podem ser identificados por um nome e atribuídos a diferentes usuários (ex. view engineering, view admins, etc..)

```
username usr view viewname
```

```
enable view viewname
```

### LINE AUTHENTICATION

##### LOCAL USER DATABASE
Solicita usuário e senha
```line# login local```

##### PER LINE PASSWORD
Solicita apenas a senha
```line# password pass``` 
```line# login```
