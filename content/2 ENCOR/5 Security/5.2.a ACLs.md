As ACLs funcionam como filtros de tráfego, permitindo ou bloqueando pacotes com base em critérios como IP de origem, destino e protocolos.

### Tipos de ACL

- Standard ACL
  - Filtra apenas pelo IP de origem.
  - Normalmente usa números de `1–99`.

Exemplo:
```
Router(config)# access-list 10 permit 192.168.1.0 0.0.0.255
```

- Extended ACL
  - Filtra por:
    - IP de origem
    - IP de destino
    - protocolo (TCP, UDP, ICMP)
    - portas
    - Usa os números de `100 >`

Exemplo:
```
Router(config)# access-list 100 permit tcp any any eq 80
```

- Aplicação da ACL em interfaces
  - ACLs precisam ser aplicadas em uma interface e direção:
    - `in` → entrada
    - `out` → saída

Exemplo:
```
Router(config)# interface g0/0
Router(config-if)#ip access-group 10 in
```

- Regra implícita
  - Toda ACL possui automaticamente: um deny all no final da lista. Se nenhum pacote corresponder às regras, ele será bloqueado.

```
deny any
```

- Verificação
  - Comandos importantes:

```
show access-lists
show ip interface
show running-config
```

- **Boas práticas**
  - Standard ACL → perto do destino.
  - Extended ACL → perto da origem.
  - Colocar regras mais específicas antes das genéricas.
