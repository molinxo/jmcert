### REST API AUTHENTICATION
Autenticação de API barra requisições de usuários não autorizados, dificultando acesso á dados sensíveis ou modificação de aplicação.

REST API's usam vários tipos de autenticação para verificar a identificação do cliente e acessar recursos de forma segura. São chamados de Métodos e Esquemas.

##### Basic Authentication:
- Usa username e password codificado em Base64 mas não possui criptografia.
- Requer HTTPS (TLS) para segurança já que os dados são enviados em cleartext á cada requisição. 
##### Bearer Authentication:
- Usa um Bearer token enviado por um Auth Server ao invés de nome e senha.
- Tokens expiram após certo tempo mas podem ser roubados caso não protegidos.
##### API Key Authentication:
- Usa uma static key emitida pelo provedor da API para autenticação.
- Bom para localizar uso de API.
- Fácil de implementar mas é menos seguro já que as chaves que são roubadas continuam válidas até que sejam revogadas.
##### OAuth2.0
- Oferece access delegation, permitindo que acesso limitado á aplicativos third-party aos recursos da rede.
- Usa tokens de acesso que expiram e podem ser recarregados sem que o usuário seja re-autenticado.
