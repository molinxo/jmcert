- User awareness: programas desenvolvidos para fazer com que usuários se atentem á potenciais riscos de segurança.

- User training: programas formais com intuito de ensinar o usuário final sobre potenciais riscos.

- Physical access control: proteção de equipamentos e dados de potenciais invasores, permitindo apenas usuários autorizados nas áreas protegidas como rack de rede e um andar de data-center.
