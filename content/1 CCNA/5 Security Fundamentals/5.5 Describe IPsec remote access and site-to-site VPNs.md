IPsec: é um conjunto de protocolos desenvolvidos para garantir a segurança dos dados transmitidos por uma rede IP. IPsec garante confidencialidade, integridade e autenticação entre dois peers.

IPsec Remote Access VPN
- Individual User Access: desenvolvido para usuários se conectarem de estações remotas
- Comunicação segura: Usa protocolos IPsec para criptografar dados entre o usuário e a rede.
- Software de client: Usuários usam um software client de VPN nos seus aparelhos para estabelecer a conexão de VPN.

Como funciona?
1. Iniciação pelo client de VPN: Usuário inicia a conexão.
2. Autenticação: O client e o gateway da VPN autentica cada chave, certificado digital e outros métodos.
3. Estabelecimento Tunnel IPsec: Assim que for autentica, um túnel IPsec é estabelecido entre client e gateway.

IPsec Site-to-Site VPN
- Conecta redes inteiras ao invés de aparelhos individuais.
- Túneis permanentes: É comum que túneis estejam sempre habilitados para manter conexão contínua entre os sites
- Gerenciamento centralizado: Configuração e gerenciamento são feitos pelos administradores das redes em cada site.

Como funciona?
1. Configuração do gateway de VPN: Cada site deve ter o seu gateway VPN configurado para estabelecer a conexão
2. Autenticação mútua: Os gateways autenticam um ao outro
3. Estabelecimento do túnel IPsec: Túnel é estabelecido entre os dois gateways criando um canal de comunicação
