### DHCP snooping
O DHCP snooping protege a rede contra servidores DHCP falsos

##### Ataques relacionados:

O switch diferencia:
- Trusted ports: ligadas ao servidor DHCP
- Untrusted ports: portas de usuário

Funções:
- Bloqueia respostas DHCP não autorizadas
- Cria uma tabela de bindings IP/MAC

##### Configuração:
```
Switch(config)# ip dhcp snooping
Switch(config)# ip dhcp snooping vlan 10

Switch(config)# interface g0/1
Switch(config-if)# ip dhcp snooping trust
```

##### Verificação:
```
show ip dhcp snooping
show ip dhcp snooping binding
```

### Dynamic ARP inspection
o DAI protege contra ataques de ARP spoofing e ARP poisoning

Ele usa a tabela criada pelo DHCP Snooping para validar pacotes ARP. Se o ARP recebido não for correspondido o pacote é descartado.

### Port Security
O Port Security limita quais e quantos devices poderão se conectar á uma interface de Switch com base no endereço MAC.

Funções principais:
- limitar quantidade de MACs;
- definir MACs permitidos;
- bloquear dispositivos desconhecidos.

Tipos de violação:

- `shutdown` → desativa a porta E REGISTA SYSLOG E SNMP; Aumenta o violation counter em 1
- `restrict` → bloqueia FRAMES e registra (SYSLOG E SNMP); Aumenta o violation counter em 1 para cada FRAME não autorizado
- `protect` → apenas bloqueia FRAMES; a interface NÃO é desabilitada; NÃO incrementa erros.

Função Sticky MAC:
- Aprende automaticamente os MACs conectados.
- Adiciona o MAC na configuração do aparelho.
- MAC na tabela MAC registrado como STATIC apesar de ser um endereço aprendido dinamicamente
- `Switch(config-if)# switchport port-security mac-address sticky`
##### Configuração:
```
Switch(config)# interface f0/1  
Switch(config-if)# switchport mode access  
Switch(config-if)# switchport port-security  
Switch(config-if)# switchport port-security maximum 2  
Switch(config-if)# switchport port-security violation shutdown
```

##### Verificação:
```
show port-security  
show port-security interface f0/1
```
