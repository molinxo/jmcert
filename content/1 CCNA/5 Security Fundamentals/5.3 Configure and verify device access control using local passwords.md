Senhas locais são a configuração de segurança básica dos switches e roteadores CISCO para controlar o acesso ao dispositivo.

Principais pontos da configuração são:

- Configuração de senhas no modo privilegiado
  - ```enable password``` - sem criptografia
  - ```enable secret``` - com criptografia

- Proteção do acesso via console
  - Configura a senha para quem conecta fisicamente via console
```
Router(config)# line console 0
Router(config-line)# password senhaConsole
Router(config-line)# login
```

- Proteção de acesso remoto (VTY)
  - Controla acesso via TELNET ou SSH
```
Router(config)# line vty 0 4
Router(config-line)# password senhaVTY
Router(config-line)# login
```

- Criptografia das senhas
  - O comando abaixo impede que senhas apareçam em texto puro no arquivo de configuração:
```
Router(config)# service password-encryption
```

- Verificação consiste em procurar as senhas usando os comandos:
  - ```show running-config```
  - ```show startup config```
