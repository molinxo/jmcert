- Nat é um protocolo usado para modificar o endereço IP de origem/destino dos pacotes.
- Permite que hosts com endereços IP's privados se comuniquem através da Internet.
- NAT estático refere-se á configuração estática do mapeamento um-a-um dos endereços IP privados para públicos.
- Inside Local = O endereço IP dos hosts dentro da rede, da perspectiva local.
- Inside Global = O endereço IP dos hosts dentro da rede, da perspectiva global.
- Outside local = IP de fora da rede, da perspectiva local
- Outside Global = IP de fora da rede, da perspectiva global
- Inside/Outside = Localização do host
- Local/Global = Perspectiva

### Dynamic NAT
- O roteador dinamicamente mapeia endereços inside local para endereços inside global quando necessário.
- Uma ACL é usada para identificar qual tráfego deve ser traduzido.
- Se o endereço de origem é permitido pela ACL
  - O endereço origem será traduzido
- Se o endereço de origem é negado pela ACL
  - O endereço IP não será traduzido e o pacote será dropado

- Uma pool NAT é usada para definir os endereços que podem ser usados
- Embora seja dinâmico eles ainda são um-a-um

- Se não houver endereços inside global disponíveis suficiente, é chamado Exaustão de pool NAT
- O roteador descarta o pacote se não houver endereços suficiente.
- Entradas de NAT dinâmico sofrerão time-out automaticamente se não forem usados, esse processo pode ser feito manualmente.

### PAT (NAT Overload)
- PAT traduz ambos endereços IPs e número da porta (se necessário)
- Usando um número de porta para cada flow de aplicação, um único endereço público pode ser usado por vários hosts internos diferentes
- O roteador irá acompanhar cada endereço inside local que está usando qualquer endereço inside global e a porta.

## Configuração

#### NAT estática

1. Configure a interface no AS Inside Global
```ip nat outside```

2. Configure a interface no AS Inside Local
```ip nat inside```

3. Por último, habilite o Static Nat usando o comando: 
```
Router(config)#ip nat inside source 
static <outside-global-ip> <outside-local-ip>
```

Exemplo:
```
R1(config)#int f0/0
R1(config-if)#ip nat outside
R1(config-if)#exit
R1(config)#int f1/0
R1(config-if)#ip nat inside
R1(config-if)#exit
R1(config)#ip nat outside source static 30.1.1.1 192.168.1.2
```

Para verificar as traduções NAT 
```R1#show ip nat translations```

#### NAT dinâmica

1. Configure a interface no AS Inside Global
```ip nat outside```

2. Configure a interface no AS Inside Local
 ```ip nat inside```

3. Crie uma pool de endereços IP's globais: 
```
Router(config)#ip nat pool <pool-name> 
<starting-IP> <ending-IP> prefix-length <prefix-length>
```

4. Crie uma access list para permitir uma rede específica de endereços IP: 
```
Router(config)#access-list <acl-number> 
permit <source-ip-network> <wildcard-mask>
```

5. Por último, habilite o Dynamic NAT usando o commando:
```
Router(config)#ip nat inside source 
list <acl-number> pool <pool-name>
```
