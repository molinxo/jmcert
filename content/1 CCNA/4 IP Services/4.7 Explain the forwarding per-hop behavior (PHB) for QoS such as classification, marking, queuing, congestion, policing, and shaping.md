QOS é utilizado para gerenciar os seguintes parâmetros:

- Largura de banda
  - A capacidade máxima do link, medido em bits por segundo (Kbps, Mbps, Gbps)

- Delay
  - A quantidade de tempo que o tráfego leva de origem ao destino sendo considerado como 'one-way' e 'two way' caso o tráfego bata no destino e volte.

- Atraso
  - A variação no delay 'one-way' entre pacotes enviados pela mesma aplicação

- Perda
  - A % de pacotes enviados que não alcançam o destino
  - Pode ser causado pelo cabeamento
  - Também podem ser causados quando a fila de pacotes de um device enche fazendo com que o device comece a descartar.


### Tipos de tráfego
Existem diferentes tipos de tráfegos que devem ser tratados de forma diferente dependendo da sensibilidade da aplicação e suas peculiaridades. Toda a parte de QoS se baseia em manipular o tráfego para manter a confiabilidade da rede.

Por um exemplo, tráfego de dados WEB precisam de um tratamento menos intensivo do que o tráfego de uma aplicação crítica.
##### Voz e video
Como dito anteriormente existe uma forma correta de tratar o tráfego dependendo dos dados e da aplicação. Voz e vídeo são exemplos de tráfego sensível que deve ser tratado para funcionamento adequado. Esses dois tipos de tráfego são objetos de estudo principais do tópico QoS para o CCNA.

### Classificação
- Forma de categorização do tráfego (pacotes) em categorias de tráfego.

- Existem vários me1todos de classificar tráfego como por exemplo
- Uma ACL. tráfego que é permitido pela ACL será dado um tratamento específico. enquanto outro tráfego não.
- NBAR (Network Based Application Recognition) realiza uma inspeção profunda no pacote verificando além da informação dos layers 3 e 4 até o layer 7 para identificar tipos específicos de tráfego.
- Nos headers do layer 2 e 3 existem fields específicos usados para esse propósito.

- O field PCP (Priority Code Point) da tag 802.1Q no header Ethernet pode ser usado para identificar alto/baixo tráfego. (Apenas quando há uma tag 802.1Q 'vlan')
- O field DSCP (Differentiated Services Code Point) do header IP também pode ser usado

### PCP/COS

PCP também conhecido como CoS Class of Service são 3 bits (8 variações possíveis)

| Valor PCP | Tipos de tráfego      |
| --------- | --------------------- |
| 0         | Best effort (padrão)  |
| 1         | Background            |
| 2         | Excelent effort       |
| 3         | Critical Applications |
| 4         | Video                 |
| 5         | Voice                 |
| 6         | Internetwork Control  |
| 7         | Network Control       |
- Entrega 'Best Effort' significa que não há garantia que o dado será entregue ou que ele siga qualquer regra QoS. esse é o tráfego regular. não é a prioridade máxima.
- IP phones marcam tráfego de ligações como PCP3
- O tráfego de voz é marcado como PCP5
