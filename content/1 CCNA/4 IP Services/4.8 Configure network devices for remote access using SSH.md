SSH é um protocolo de acesso remoto, hoje em dia é o padrão de uso pelas melhorias na segurança em comparação com o TELNET

Por padrão, não é necessária uma senha para acessar o CLI do device Cisco via console.

Usando SSH você pode configurar login e senha.

Switches de Layer 2 não executam roteamento de pacotes, eles não são cientes de roteamento IP. Entretanto é possível configurar uma SVI para alocação de um endereço IP para permitir acesso remoto á CLI do switch.

Para habilitar e usar o SSH é necessário gerar um par de chaves RSA pública e privada.

#### Passos
1. Configurar um hostname
2. Configurar o domínio
3. Gerar o par de chaves RSA
4. Configurar enable password e username
5. Habilitar o SSHv2
6. Configurar as VTY lines
### Configuração SSH: RSA Keys
```
SW1(config)#ip domain ccna.com

SW1(config)#crypto key generate rsa
```

#### Configuração SSH: VTY Lines
```
SW1(config)#enable secret ccna

SW1(config)#username cisco secret ccna

SW1(config)#access-list 1 permit host 192.168.2.1

SW1(config)#ip ssh version 2

SW1(config)#line vty 0 15

SW1(config-line)#login local

SW1(config-line)#exec-timeout 5 0 

SW1(config-line)#transport input ssh

SW1(config-line)#access-class 1 in
```
