- Configurar o tempo dos devices manualmente não é escalável.
- A configuração manual dos relógios causarão um drift, resultando no tempo errado.

- NTP permite sync automático do tempo.
- Clientes NTP fazem o request do tempo de outros servidores NTP.
- Um aparelho pode ser um servidor e cliente NTP ao mesmo tempo.

- NTP permite acuracy do tempo entre 1 milisegundo se o servidor estiver na mesma LAN e 50 milisegundos através da WAN/Internet

- A distância entre o servidor NTP e o relógio de referência original é chamada de 'Stratum'.
  Relógio de referência são Stratum 0, Servidores NTP são Stratum 1 e pegam o tempo dos relógios de referência, Stratum 15 é o máximo. Tudo acima disso é considerado não confiável.

## Configuração
#### Configurar servidor NTP

```
ntp server pool.ntp.org
```

Sincroniza o relógio com um servidor NTP público.

---

#### Verificar associações NTP

```
show ntp associations
```

Mostra servidores NTP e status da sincronização.

---

#### Verificar status NTP

```
show ntp status
```

Exibe informações detalhadas da sincronização.

---

#### Ver relógio do sistema

```
show clock
```

Mostra o relógio de software.

---

#### Ver relógio de hardware

```
show calendar
```

Mostra o relógio físico do equipamento.

---

#### Atualizar relógio de hardware

```
ntp update-calendar
```

Sincroniza o relógio físico com o relógio do sistema.

---

#### Configurar switch como cliente NTP

```
ntp server 192.168.123.3
```

Define o roteador como servidor NTP do switch.

---

## Configurar modo peer NTP

```
ntp peer 192.168.123.2
```

Permite sincronização entre dispositivos NTP (backup).
