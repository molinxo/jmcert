SNMP ajuda a gerenciar e monitorar equipamentos na rede.

NMS ou Network Management Station são os servidores SNMP que gerencia os equipamentos.
- NMS recebe notificações dos devices
- NMS altera configurações dos devices
- NMS checa o status dos devices

Variáveis como a interface, traffic, etc.. são armazenadas no MIB ou Management Information Base e identificados usando Object ID's (OIDs)

Versões principais do SNMP é SNMPv1,SNMPv2c e SNMPv3

Mensagens SNMP são: GET, GET NEXT, GET BULK, SET, TRAP, INFORMA E RESPONSE

| Mensagem                   | SNMP Version | Função                                           |
| -------------------------- | ------------ | ------------------------------------------------ |
| **GetRequest**             | v1, v2c, v3  | Solicita o valor de um objeto                    |
| **GetNextRequest**         | v1, v2c, v3  | Solicita o próximo objeto da MIB                 |
| **GetBulkRequest**         | v2c, v3      | Obtém grandes quantidades de dados de uma só vez |
| **SetRequest**             | v1, v2c, v3  | Modifica um valor no agente                      |
| **Response** (GetResponse) | v1, v2c, v3  | Resposta a Get, GetNext, GetBulk e Set           |
| **Trap**                   | v1, v2c, v3  | Notificação assíncrona enviada pelo agente       |
| **InformRequest**          | v2c, v3      | Notificação que exige confirmação                |

### Portas SNMP

- **UDP 161** → Get, GetNext, Set
- **UDP 162** → Trap e Inform
