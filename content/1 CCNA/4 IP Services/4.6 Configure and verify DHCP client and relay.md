### DHCP Relay
Alguns engenheiros podem escolher configurar cada roteador para agir como um servidor DHCP para suas LAN's conectadas.

Entretanto, empresas grandes comumente escolhem usar um servidor DHCP centralizado.

Se o servidor é centralizado, ele não receberá as mensagens broadcast DHCP.

Para resolver isso, pode ser configurado um roteador para agir como agente DHCP relay.

O roteador irá encaminhar as mensagens broadcast DHCP dos clientes, para o servidor DHCP como mensagens Unicast.

### Configuração de servidor DHCP no CISCO IOS

Exclui os endereços que não poderão ser usados, reservados.
```R1 (config)# ip dhcp excluded 192.168.1.1 192.168.1.10```

Cria uma pool DHCP e escolhe o nome dela
```R1 (config)#ip dhcp pool LAB_POOL```

Especifica qual rede e sub-rede serão usado pelos clientes
```R1 (dhcp-config)#network 192.168.1.0 /24```

Configuração do servidor dns que será usado pelos clientes
```R1 (dhcp-config)#dns-server 8.8.8.8```

Especifica o nome do domínio da rede.
```R1 (dhcp-config)#domain-name ccna.com```

Especifica o gateway da rede.
```R1 (dhcp-config)#default-router 192.168.1.1```

Especifica o tempo que será 'lease dias horas minutos'
```R1 (dhcp-config)# lease 0 5 30```

##### Verificação no servidor
```R1# show ip dhcp binding```

### Configuração DHCP Relay Agent

R1(config)#interface g0/1
R1(config-if)# ip helper-address 192.168.10.10

### Configuração DHCP Cliente

R1(config)#interface g0/1
R1(config-if)#ip address dhcp
