TFTP e FTP são protocolos para envio de arquivos

### TFTP
- Não é necessária autenticação, servidores irão responder á qualquer requisição TFTP
- Não criptografa, os dados são enviados como plain text
- Servidores TFTP usam a porta UDP 69

- Todas as mensagens de dados TFTP são reconhecidas.
  - Se o cliente está transferindo um arquivo para o servidor, o servidor irá enviar uma mensagem Ack
  - Se o servidor está transferindo um arquivo para o cliente, o cliente irá enviar uma mensagem Ack
  - Temporizadores são usados e se uma mensagem esperada não for recebida, o device receptor irá reenviar.

TFTP possui três fases
1. Conexão: Request para o servidor
2. Transferência de dados: Um envia dados e o outro envia mensagens Ack
3. Término da conexão.

### FTP
- File Transfer Protocol é mais complexo que o TFTP e permite não somente transferência de arquivos, mas clientes também podem navegar por diretórios, adicionar e remover diretórios, listar arquivos, etc..
- O cliente envia comandos FTP para o servidor executar essas funções.
- Usa o TCP (20 para dados e 21 para controle) para comunicação baseada em conexão.
