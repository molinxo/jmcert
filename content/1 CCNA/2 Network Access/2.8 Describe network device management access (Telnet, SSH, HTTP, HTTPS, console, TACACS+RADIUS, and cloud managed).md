### Console

Usado durante o setup inicial do aparelho, enquanto ele ainda não possui endereços IP's configurados ou durante a recuperação ou manutenção de um device. É necessário acesso físico ao device.

Esse método SEMPRE estará disponível mesmo se o aparelho não tiver um endereço IP configurado.

### Telnet
É um protocolo de rede que habilita a conexão remota de aparelhos. Telnet usa a porta TCP 23. Esse método é pouco usado hoje em dia por consenso de que há falhas de segurança já que o protocolo transmite dados em texto, o que facilita a captura. por isso hoje é preferido usar o SSH.

### SSH
É um protocolo de rede que habilita conexão remota segura de computadores. SSH usa a porta TCP 22. usa criptografia para proteger os dados durante a transmissão e criptografa todos os dados inclusive credenciais de login. Hoje em dia é o método mais usado.

### HTTP / HTTPS
Podem ser usados para acessar interfaces gráficas baseadas em web de aparelhos de rede para configuração e monitoria. HTTP oferece uma web GUI utilizando a porta TCP 80 mas não criptografa os dados. enquanto HTTPS é um método seguro que criptografa os dados (SSL/TLS) utilizando a porta TCP 443.

Esse método é utilizado para aparelhos que possuem uma GUI (Graphic User Interface).

### TACACS+ e RADIUS

Usados para AAA (Authentication, Authorization e Accounting)

RADIUS é um protocolo de código aberto comumente utilizado para autenticação de usuário e autorização para acesso na rede. Ele criptografa apenas as senhas e utiliza as portas UDP 1812 para Authentication e UDP 1813 para Accounting. Comumente utilizado para autenticação wireless, conexões VPN e serviços de provedoras.

É utilizado quando apenas a senha receber criptografia já é o suficiente.

TACACS+ é um protocolo proprietário CISCO e foca mais em acesso administrativo para equipamentos de redes. TACACS+ opera na porta TCP 49 e criptografa todos os dados do pacote adicionando uma camada a mais de segurança. É comumente utilizado para gerenciar acesso de equipamentos como Switches e Roteadores.

### Cloud managed
É o método de gerenciar um aparelho pela plataforma cloud do distribuidor assim como o Cisco Meraki, a principal característica
do cloud é o gerenciamento centralizado pois provém um único ponto de controle independente da localização dos aparelhos.

A Cloud pode reduzir custos de hardware e estrutura assim como custos de manutenção.
