A tradução literal para o português seria "Portas Tronco" são portas que carregam tráfego de diversas VLAN's na mesma interface.

Normalmente interfaces Trunk são configuradas em conexões com outros Switches ou Roteadores já que são responsáveis por carregar altas cargas de tráfego em diferentes VLANs.

Switches irão 'taggear' todos os quadros que eles enviam por um link trunk. Isso permite que o switch receptor identifique á qual VLAN o frame pertence.

- Para configurar a interface como trunk é necessário o comando
```
SW1(config)#interface fastEthernet 0/3
SW1(config-if)#switchport mode trunk
```

- Para habilitar diferentes VLAN's no Trunk use o seguinte comando
```
SW1(config)#interface fastEthernet 0/3
SW1(config-if)#switchport trunk allowed vlan 1,2,3,4
```

### Dynamic Trunking Protocol (DTP)

Refere-se ao protocolo proprietário da CISCO de Trunk dinâmico. Pense por um instante, configuração de VLAN pode ser extensiva em redes grandes e um link trunk pode não funcionar devido conflito na configuração.

Um link entre uma interface trunk e uma interface de acesso irá descartar todos os pacotes enviados por ambas as interfaces já que o link de acesso não reconhece informações 802.1Q no cabeçalho do frame. Os modos DTP foram criados para resolver problemas como esse de forma dinâmica.

Modos DTP:

On ou Trunk mode: Nesse modo a interface se inicia como uma porta trunk e assume que a interface do outro lado também será uma porta trunk. esse modo gera mensagens DTP e adiciona informações de VLAN aos quadros.

Desirable mode: Nesse modo a interface se inicia como porta de acesso e gera mensagens DTP, transforma-se em trunk caso a interface do outro lado responda essas mensagens DTP. Caso a interface remota não responda essas mensagens DTP, a interface local se mantém em access.

Auto mode: Nesse modo a interface não gera pacotes DTP apenas recebe essas mensagens, caso receba uma mensagem DTP assume que a interface remota é trunk e se transforma em trunk também

No-negotiate: Nesse modo a interface se inicia como trunk e adiciona informações de VLAN normalmente mas não gera mensagens DTP. Este modo é usado para caso o switch do outro lado não seja um switch cisco por um exemplo (Não possuir DTP)

OFF: Nesse modo a interface se inicia em Access e mantém a porta aberta. Não encaminha mensagens DTP e não adiciona informações de VLAN.
