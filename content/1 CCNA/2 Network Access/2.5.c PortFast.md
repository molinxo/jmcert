O recurso PortFast faz com que uma porta de switch entre imediatamente no estado de encaminhamento da árvore de abrangência (spanning tree forwarding state), ignorando os estados de escuta e aprendizado (listening) e de aprendizado (learning). 

O PortFast em portas de switch conectadas a uma única estação de trabalho ou servidor permite que esses dispositivos se conectem à rede imediatamente, em vez de esperar que a porta faça a transição dos estados de escuta e aprendizado para o estado de encaminhamento.

_Para configurar o recurso PortFast do Spanning Tree, insira os comandos abaixo:_

```
Switch# configure terminal
Switch(config)# interface FastEthernet 0/1
Switch(config-if)# spanning-tree portfast
Switch(config-if)# end   
Switch(config)# show spanning-tree
```
