LAN virtual ou VLAN refere-se ao agrupamento lógico de devices dentro de uma rede que permite com que eles se comuniquem como se estivessem na mesma rede local, mesmo que fisicamente estejam em switches diferentes.

- Reduz o tráfego de transmissão desnecessário, aumenta a segurança e melhora o desempenho, a flexibilidade e a capacidade de gerenciamento da rede.
- Tradicionalmente, os domínios de transmissão eram separados usando dispositivos da Camada 3 (roteadores).
- Mesma VLAN: os dispositivos se comunicam diretamente no mesmo domínio de transmissão.
- VLANs diferentes: A comunicação requer roteamento entre VLANs por meio de um roteador ou switch de camada 3 (SVI).

##### VLAN ID Ranges (padrão Cisco)
- **VLAN 0 e VLAN 4095:** Os IDs de VLAN reservados são definidos pelo IEEE 802.1Q e usados ​​internamente para operações de protocolo e não podem ser configurados ou atribuídos a portas.
- **VLAN 1 (VLAN padrão):** A VLAN padrão nos switches Cisco e todas as portas do switch são atribuídas à VLAN 1 por padrão. Ele não pode ser excluído e é comumente usado para protocolos de controle e gerenciamento como STP, CDP e VTP.
- **VLAN 2 a VLAN 1001** **(intervalo de VLAN normal):** Este intervalo é usado para configuração de VLAN regular. As VLANs nesta faixa são totalmente configuráveis, editáveis ​​e deliciosas e são armazenadas no banco de dados de VLAN do switch.
- **VLAN 1002 a VLAN 1005:** VLANs reservadas para tecnologias de rede legadas, como FDDI e Token Ring. Estas VLANs são predefinidas e não podem ser removidas, mesmo que as tecnologias não estejam mais em uso.
- **VLAN 1006 a VLAN 4094 (Extended VLAN Range):** Projetado para redes de grande escala que exigem um grande número de VLANs. As VLANs nesse intervalo são armazenadas na configuração em execução e normalmente exigem que o switch opere no modo VTP transparente.

### Configuração padrão das VLAN's
```
****Create VLANs****  
Switch(config) vlan 2

Switch(config-vlan) name Accounts

Switch(config) vlan 3

Switch(config-vlan) name HR  
  
****Assign switch ports to VLANs****  
Switch(config) interface fa0/0

Switch(config-if) switchport mode access

Switch(config-if) switchport access vlan 2

Switch(config) interface fa0/1

Switch(config-if) switchport mode access

Switch(config-if) switchport access vlan 3
```

### Modos de VTP

Você pode configurar um interruptor para operar-se em qualquer destes modos de VTP:

- Server - No modo do servidor VTP, você pode criar, alterar, e suprimir de VLAN e especificar outros parâmetros de configuração, tais como a versão de VTP e a poda de VTP, para o VTP domain inteiro. Os servidores VTP anunciam sua configuração de VLAN a outros devices no mesmo VTP domain e sincronizam sua configuração de VLAN com outros devices baseados nas propagandas recebidas sobre enlaces de tronco. O servidor VTP é o modo padrão.

- Cliente - Os clientes VTP comportam-se da mesma maneira que os servidores VTP, mas você não podem criar, mudar, ou suprimir de VLAN em um cliente VTP.

- Transparente - Os switches transparentes VTP não participam no VTP. Um switch transparente VTP não anuncia sua configuração de VLAN e não sincroniza sua configuração de VLAN baseada em propagandas recebidas, mas os switches transparentes enviam os anúncios de VTP que recebem para fora suas portas trunk na versão de VTP 2.

- Desligado — Nos três modos descritos, os anúncios VTP são recebidos e transmitidos assim que o switch entra no estado do domínio de gerenciamento. No modo desligado VTP, os interruptores comportam-se do mesmos que no modo transparente VTP com exceção dos anúncios de VTP não são enviados.
### VTP V2

O VTP V2 não é muito diferente do VTP V1. A principal diferença é que o VTP V2 introduz suporte para VLANs Token Ring. Se você usa VLANs Token Ring, você deve habilitar o VTP V2. Caso contrário, não há motivo para usar o VTP V2. A alteração da versão do VTP de 1 para 2 não faz com que um switch seja recarregado.

### Senha de VTP

Se você configura uma senha para o VTP, você deve configurar a senha em todos os interruptores no VTP domain. A senha deve ser a mesma senha em todos aqueles interruptores. A senha de VTP que você configura é traduzida pelo algoritmo em uma palavra 16-byte (valor MD5) que seja levada dentro todos os pacotes de VTP de anúncio de sumário.
