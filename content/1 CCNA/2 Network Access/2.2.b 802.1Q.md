O IEEE 802.1Q é um dos protocolos de marcação de VLAN (VLAN tagging) suportados pelos switches Cisco. Esse padrão foi criado pelo Institute of Electrical and Electronics Engineers (IEEE), portanto é um padrão aberto e pode ser utilizado em switches que não sejam da Cisco.

As tags VLAN 802.1Q são inseridas no cabeçalho dos quadros Ethernet para identificar tráfego de múltiplas VLANs e também tráfego de VLANs sem tag (untagged VLANs).

##### Original Frame

| Destination MAC | Source MAC | Length/Type | Data | FCS |
| --------------- | ---------- | ----------- | ---- | --- |

##### 802.1Q Frame:

| Destination MAC | Source MAC | 802.1Q Tag | Length/Type | Data | FCS |
| --------------- | ---------- | ---------- | ----------- | ---- | --- |

- O tag 802.1Q é inserido entre os quadros Source MAC e o Type/Length 
- A tag tem 4bytes no total(32 bits)
- A tag consiste em dois principais campos.
- Tag Protocol Identifier (TPID)
- Tag Control Information (TCI)
- O TCI consiste em três principais sub-campos

##### 802.1Q Tag format

| 16 bits | 3 bits | 1 bit | 12 bits |
| ------- | ------ | ----- | ------- |
| TPID    | TCI    | TCI   | TCI     |
| TPID    | PCP    | DEI   | VID     |
- TPID - 16bits (2 bytes): Definido sempre como 0x8100 para indicar o 802.1Q
- PCP (Priority code point) - 3bits: Usado para Class of Service (CoS)
- DEI (Drop Eligible Indicator) - 1bit: Usado para indicar frames que podem ser descartados caso a rede esteja congestionada.
- VID (VLAN ID) - 12bits: 
  - Identifica a VLAN que o frame pertence.
  - 4096 possíveis VLAN's (2ˆ12) range de 0-4095
  - VLAN's 0 e 4095 são reservadas
  - O Range mesmo é de 1-4094
