Todos os switches se tornam membros da VLAN Default logo após o boot inicial do switch. Todas as interfaces tornam-se então parte de um único domínio de broadcast.
No CISCO o padrão é que a VLAN Default seja a VLAN1

Não confundir com a VLAN Native (tópico 2.4.a) diferentemente da VLAN Nativa a Default não pode ser alterada e não pode ser desabilitada. abaixo estão algumas das diferenças:

| Criterio                               | Default VLAN                                                                                                                                                                                                                        | Native VLAN                                                                       |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Modificação da VLAN                    | A VLAN Default é sempre a VLAN 1 e isso não pode ser alterado.                                                                                                                                                                      | Por padrão a VLAN Native é a VLAN 1 mas isso pode ser alterado para qualquer VLAN |
| Tráfego sem marcação na VLAN           | Tráfego não marcado será enviado somente se VLAN Native e a Default sejam a mesma                                                                                                                                                   | Tráfego não marcado será enviado independente da Native e Default serem a mesma.  |
| Operand                                | A VLAN padrão é especificada através do comando operand VLAN.                                                                                                                                                                       | A VLAN nativa é especificada através do comando operand NATIVE.                   |
| Desabilitar a VLAN                     | Não é possível desabilitar a VLAN Default                                                                                                                                                                                           | É possível desabilitar a VLAN                                                     |
| Tipo de encapsulamento                 | Suporta .1Q e ISL.                                                                                                                                                                                                                  | Suporta apenas .1Q.                                                               |
| Marcação (Tagging)                     | É possível taggear o tráfego na VLAN Default.                                                                                                                                                                                       | Tagging é possível na VLAN Native mas por padrão não é taggedo.                   |
| Valor padrão da VLAN                   | 1 (faixa normal). Essa VLAN pode ser usada, mas não pode ser excluída. É a VLAN padrão da Cisco. As VLANs 1002 a 1005 também são padrões Cisco para Token Ring e FDDI (Fiber Distributed Data Interface) e não podem ser excluídas. | Qualquer VLAN por porta trunk .1Q.                                                |
| DTP(Dynamic Trunking Protocol) traffic | O DTP não é enviado pela VLAN Default.                                                                                                                                                                                              | O DTP é enviado pela VLAN nativa.                                                 |
| Número máximo de VLAN's no switch      | Uma VLAN padrão por switch.                                                                                                                                                                                                         | s VLANs Native podem ser tantas quanto o número de trunks .1Q no switch.          |
