Cisco Discovery Protocol (CDP) é um protocolo proprietário Cisco para descobrimento da rede na camada data link. Ele compartilha informações como o nome do device e a versão do IOS com outros aparelhos Cisco conectados.

Link Layer Discovery Protocol (LLDP) é um protocolo aberto que usa a camada data link para descobrimento da rede.

Os dispositivos de rede anunciam informações, como suas identidades e capacidades, para seus vizinhos.

### Configuração

Inicialmente É necessário habilitar globalmente o CDP/LLDP

```
Router(config)# cdp run  
Router(config)# exit  
Router# show cdp  
% CDP is enabled
```

Outra é possível é desativá-lo apenas em alguma(s) interface(s):  
  
```
Router(config)# interface g0/0  
Router(config-if)# no cdp enable
```

LLDP
```
Router# show lldp  
% LLDP is not enabled  
Router# configure terminal  
Router(config)# lldp run  
Router(config)# exit  
Router# show lldp

    Status: ACTIVE  
    LLDP advertisements are sent every 30 seconds  
    LLDP hold time advertised is 120 seconds

```
