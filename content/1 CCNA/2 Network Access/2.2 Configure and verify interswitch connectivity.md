Um switch de camada 3 pode rotear de uma VLAN para outra utilizando múltiplas Switch Virtual Interfaces (SVIs). Os switches de camada 3 convertem uma interface de switch de camada 2 em uma interface de camada 3, tornando-a uma porta roteada, semelhante a uma interface física em um roteador Cisco IOS.

1. Habilite a capacidade de roteamento no switch. Embora esse comando normalmente já venha habilitado, não custa garantir que ele esteja ativo.

```
Switch(config)# ip routing
```

2. Adicione as VLAN's no banco de dados do Switch.
```
Switch#vlan database
Switch(vlan)#vlan 10
VLAN 10 added:
    Name: VLAN0010
```

3. Crie as SVI e configure o endereço IP nas interfaces VLAN's
```
Switch#configure terminal
Enter configuration commands, one per line.  End with CNTL/Z.
Switch(config)#interface Vlan10
%LINK-5-CHANGED: Interface Vlan10, changed state to up
Switch(config-if)#ip address 192.168.10.1 255.255.255.0
Switch(config-if)#no shutdown
Switch(config-if)#interface Vlan20
%LINK-5-CHANGED: Interface Vlan20, changed state to up
Switch(config-if)#ip address 192.168.20.1 255.255.255.0
Switch(config-if)#no shutdown
Switch(config-if)#interface Vlan30
%LINK-5-CHANGED: Interface Vlan30, changed state to up
Switch(config-if)#ip address 192.168.30.1 255.255.255.0
Switch(config-if)#no shutdown
```

4. O comando `no switchport` permite que as portas físicas adquiram funcionalidade de roteamento de camada 3. O endereço IP atribuído fica dentro da mesma sub-rede do roteador padrão.
```
Switch(config)#interface FastEthernet 0/1
Switch(config-if)#no switchport
Switch(config-if)#ip address 10.1.1.1 255.255.255.0
Switch(config-if)#no shutdown
```

### Verificação de InterVLAN em Switch de Camada 3

Podemos usar os seguintes comandos `show` para confirmar que a configuração de InterVLAN no switch de camada 3 está funcionando corretamente:

- `show ip route` devolve um snapshot da tabela de roteamento.
```
Switch#show ip route
Codes: C - connected, S - static, I - IGRP, R - RIP, M - mobile, B - BGP
       D - EIGRP, EX - EIGRP external, O - OSPF, IA - OSPF inter area 
       N1 - OSPF NSSA external type 1, N2 - OSPF NSSA external type 2
       E1 - OSPF external type 1, E2 - OSPF external type 2,
       i - IS-IS, su - IS-IS summary, L1 - IS-IS level-1, L2 - IS-IS level-2,
       ia - IS-IS inter area, * - candidate default, U - per-user static route,
       o - ODR, P - periodic downloaded static route

Gateway of last resort is 10.1.1.2 to network 0.0.0.0

     10.1.1.0/30 is subnetted, 1 subnets
C       10.1.1.0 is directly connected, GigabitEthernet 0/0/0
     192.0.0.0/24 is subnetted, 3 subnets
C       192.168.10.0 is directly connected, Vlan10
C       192.168.20.0 directly connected, Vlan20
C       192.168.30.0 is directly connected, Vlan30
S*   0.0.0.0/0 [1/0] via 10.1.1.2
```

- `show ip interface brief` – exibe um resumo das informações de IP e do status das interfaces. Esse comando é usado para verificar se as interfaces VLAN e as portas do switch estão em estado up/up.
