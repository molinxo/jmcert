### Root guard
É um mecanismo do protocolo STP que proíbe um switch indesejado de se tornar o root bridge. Com o root guard administradores de rede podem manipular a seleção do root bridge.

O mecanismo root guard é importante para evitar mudanças no Bridge Root de forma indesejada. 

Root guard passa a interface que recebeu um BPDU indesejado em `inconsistent state` (Inconsistente).

```
Switch(config-if)# spanning-tree guard root
Switch# show spanning-tree inconsistentports
```

### Loop guard
STP Loop Guard é o mecanismo STP usado para proteger a rede contra os loops da camada 2. Em outras palavras, é um mecanismo de proteção de loop.

Por exemplo, um switch pode enviar BPDU, mas não pode receber nenhum BPDU do outro switch. E isso é detectado pelo UDLD. Se o Loop Guard estiver configurado, o Loop Guard coloca a porta em “Loop Inconsistence State” em vez de passar pelo estado Forwarding nesta situação. Mas se não houver Loop Guard, a porta continuará a enviar a unidade de dados do protocolo Bridge e passará pelo estado de encaminhamento. Nessa situação, ocorre um Loop da Camada 2. Loop Guard é usado principalmente para evitar tais casos.

### BPDU Guard
É um mecanismo que protege a interface de qualquer BPDU, em outras palavras, o mecanismo evita o recebimento de pacotes BPDU. O mecanismo evita o BPDU passando a interface para o estado `Error-Disabled`

Habilitando o `bpduguard` na interface
```
Switch(config-if)# spanning-tree bpduguard enabled
```

Habilitando o `bpduguard`globalmente como padrão
```
Switch(config)# spanning-tree portfast bpduguard default
```
 
### BPDU Filter
É um mecanismo que evita o recebimento de BPDUs nas interfaces e também garante que o dispositivo não participe do STP mesmo que seja um switch. Isso também é útil com portas configuradas com PortFast.

O filtro BPDU remove o PortFast da porta, se ela receber um pacote BPDU. Depois disso, opera com STP normal.

Habilitando o `bpdufilter` na interface
```
Switch(config-if)# spanning-tree bpdufilter enable
```

Habilitando o `bpdufilter` globalmente como padrão
```
Switch(config-if)# spanning-tree bpdufilter enable
```
