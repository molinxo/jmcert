Normalmente roteadores são usados para dividir o domínio de broadcast e switches (layer 2) operam em um único broadcast, mas switches também conseguem dividir o domínio de broadcast usando os conceitos de VLAN.

**VLAN** é o agrupamento lógico de dispositivos no mesmo ou em diferentes domínios de broadcast. Por padrão, todas as portas do switch pertencem à VLAN 1. À medida que um único domínio de broadcast é dividido em vários domínios de broadcast, roteadores ou switches de camada 3 são utilizados para permitir a comunicação entre as diferentes VLANs. O processo de comunicação entre diferentes VLANs é conhecido como Inter-VLAN Routing (IVR).

Suponha que tenham sido criados dois grupos lógicos de dispositivos (VLANs), chamados vendas e financeiro. Se um dispositivo do departamento de vendas quiser se comunicar com um dispositivo do departamento financeiro, será necessário realizar o roteamento entre VLANs. Isso pode ser feito utilizando um roteador ou switches de camada 3.

**Switch Virtual Interface (SVI):** SVI é uma interface lógica em um switch multilayer (camada 3) que fornece processamento de camada 3 para os pacotes de todas as portas do switch associadas àquela VLAN. Apenas uma SVI pode ser criada para cada VLAN. A SVI em um switch de camada 3 fornece serviços de gerenciamento e roteamento, enquanto a SVI em um switch de camada 2 fornece apenas serviços de gerenciamento, como criação de VLANs ou acesso Telnet/SSH.

**Processo de Inter-VLAN Routing usando um Switch de Camada 3:** A SVI criada para a VLAN correspondente atua como gateway padrão daquela VLAN, assim como a subinterface de um roteador no processo conhecido como Router-on-a-Stick. Se o pacote precisar ser enviado para uma VLAN diferente, ou seja, se o roteamento entre VLANs precisar ser realizado no switch de camada 3, o pacote será primeiro enviado ao switch de camada 3 e depois encaminhado ao destino, de forma semelhante ao processo Router-on-a-Stick.
