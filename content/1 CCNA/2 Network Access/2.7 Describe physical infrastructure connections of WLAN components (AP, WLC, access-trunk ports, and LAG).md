Overview de uma rede wireless

Para entender como uma rede wireless funciona em um setup cisco é necessário conhecer as conexões físicas entre WLC, Switches e AP's também as configurações das portas e o papel do agregador de link LAG 

Key componets roles

Access Points
São comumente conectadas á switches de acesso por ethernet, a interface pode ser configurada como access ou trunk dependendo da necessidade da rede

Tipos de deployment de AP's
- Autonomous AP
  Opera independente sem uma WLC.
- Lightweight AP
  É gerenciada pela WLC e envia tráfego via túnel CAPWAP


#### Wireless LAN Controller
É o aparelho central que gerencia e controla todas as AP's lightweight.

A WLC se conecta á um switch core ou de distribuição e as portas de uma WLC costumam ser configuradas com o 802.1Q (Trunk port) para manter várias VLANs, uma para cada SSID.

#### Switch Ports
Podem ser configuradas como Access ou Trunk, a porta em access pode enviar tráfego por uma única VLAN. por exemplo se uma rede wireless possui apenas um SSID mapeada na VLAN 10 a AP pode ser conectada á uma interface em Access. Por outro lado interfaces em Trunk carregam dados para múltiplas VLAN's, caso a rede wireless possua diversos SSIDs mapeados em VLAN's diferentes é necessário que a porta esteja configurada em Trunk.

Link-aggregation (LAG)
É um método de configuração que agrupa diversas interfaces físicas em um único link lógico para aumentar banda e redundância.

WLCs muitas vezes são conectadas ao Switch combinando várias interfaces ethernet usando LAG aumentando a disponibilidade e load-balance.

Importante! LAG para a WLC é configurado manualmente como EtherChannel Estático nas duas pontas, isso significa que não é configurado nenhum protocolo de auto-negociação como LACP ou PAgP.

#### Workflow das conexões físicas

Clientes wireless conectam-se á rede sem fio pela Access Point conectada á um Switch por uma interface Access ou Trunk. O Switch então transfere os dados para a WLC normalmente por uma interface Trunk. Então a WLC gerencia os dados das Access Points usando CAPWAP que transfere os dados para a VLAN ou Rede correta pelo túnel. LAG pode ser usado entre WLC e Switch para redundância e aumento de banda.
