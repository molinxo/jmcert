Todas as rotas listadas na tabela de roteamento possuem um código que simboliza de que maneira a rota foi aprendida pelo roteador.

| Code | Routing Protocol              |
| ---- | ----------------------------- |
| C    | Conectado diretamente         |
| L    | Local (endereço de interface) |
| S    | Rota estática                 |
| R    | RIP                           |
| D    | EIGRP                         |
| O    | OSPF                          |
| B    | BGP                           |
| *    | Candidato para rota estática  |
