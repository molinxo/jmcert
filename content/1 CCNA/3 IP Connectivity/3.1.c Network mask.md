Determina o tamanho da rede e especifica qual porção do prefixo representa a rede e qual porção representa os hosts.

no exemplo á seguir iremos representar em bits uma máscara /24 onde os bits 1 representam a porção de rede e os bits 0 representam a porção de hosts.

| Subnet Mask                | CIDR      |
| -------------------------- | --------- |
| 255.255.255.0              | /24       |
| Network                    | Host      |
| 11111111.11111111.11111111 | .00000000 |
A Máscara de redes ajuda o roteador a identificar qual parte do endereço IP precisa corresponder quando procura por rotas.
