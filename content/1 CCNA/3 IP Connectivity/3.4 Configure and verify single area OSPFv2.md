Open Shortest Path First ou OSPF é um protocolo de código aberto distance vector que usa o algoritmo djisktra para escolher a melhor rota. 

 Roteadores armazenam informação sobre a rede em LSAs (Link State Advertisement), que são organizados em uma estrutura chamada LSDB(Link State Data Base)

Irá ocorrer um flood de LSAs até que todos os roteadores na área OSPF desenvolvam o mesmo mapa da rede.

No OSPF existem três passos importantes no processo de compartilhar LSAs e determinar as melhores rotas para cada destino

1. ==Se tornar neighbor== com outros roteadores na mesma área
2. ==Trocar LSAs== com roteadores vizinhos.
3. ==Calcular a melhor rota== para cada destino e inseri-las no LSDB


### OSPF Areas

Refere-se á um grupo de roteadores e links que compartilham o mesmo LSDB.. tornando-se vizinhos.. 

Todas as áreas OSPF devem ter pelo menos um ABR (Area Border Router) conectados na área backbone.

Interfaces OSPF na mesma sub-rede devem estar na mesma área

A área backbone é uma área que todas as outras áreas se conectam

Roteadores com todas as interfaces na mesma area são chamados de roteadores internos

Roteadores com interfaces em múltiplas áreas são chamados Area Border Routers (ABR's)

Roteadores conectados na área backbone são chamados de backbone routers

Uma rota intra-area é um destino dentro da mesma área.
Uma rota inter-area é um destino fora da mesma área.

#### OSPF Cost

- Métrica de OSPF é chamada Custo
- É calculado automaticamente baseado na velocidade da interface.
- É calculado dividindo a banda de referencia pela banda da interface
- A banda padrão para referência é 100mbps.
- Todos os valores menores que 1 serão convertidos para 1
- Você deve configurar uma referencia de banda maior que o link mais veloz da sua rede.
- Você deve configurar a mesma referência para todos os roteadores OSPF na rede.
- O custo OSPF para um destino é o custo total de todas as interfaces de saída.
- Interfaces loopback possuem o custo 1

Existem três maneiras de modificar o custo OSPF
```
auto-cost reference-bandwidth mbps
ip ospf cost value ###manual
bandwidth kbps 
```

### Tipos de redes OSPF

- Broadcast 
- Non-Broadcast
- Point-to-Point
- Point-to-Multipoint
- Point-to-Multipoint Non-Broadast (Cisco)
- Loopback

Broadcast
O tipo de rede broadcast é o padrão para uma rede OSPF habilitada na interface ethernet. Ele requer um link que suporte broadcast layer 2 e mantém relações de DR/BDR.

Point-to-Point
É uma conexão entre dois pontos específicos ou roteadores OSPF. Um pacote entregue por um desses roteadores sempre será um recipiente. Esse tipo de rede não mantém relação DR/BDR. Conexões rodando PPP ou HDLC são alguns exemplos de link point-to-point.

Configuração do tipo de rede 
```
Router#conf t
Router(config)#int gi0/0
Router(config-if)#ip ospf ne
Router(config-if)#ip ospf network ?
  broadcast            Specify OSPF broadcast multi-access network
  non-broadcast        Specify OSPF NBMA network
  point-to-multipoint  Specify OSPF point-to-multipoint network
  point-to-point       Specify OSPF point-to-point network
```

Exemplo que mostra o tipo padrão da rede OSPF quando habilitado na interface ethernet
```
Router#sh ip ospf int gi0/0
GigabitEthernet0/0 is up, line protocol is up 
  Internet Address 10.1.1.1/30, Area 0, Attached via Network Statement
  Process ID 1, Router ID 1.1.1.1, Network Type BROADCAST, Cost: 1
```
