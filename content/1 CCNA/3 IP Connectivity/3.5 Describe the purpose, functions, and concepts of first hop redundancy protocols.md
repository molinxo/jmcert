- Um IP virtual é configurado nos dois roteadores e o MAC virtual é gerado para o Endereço IP virtual
- Um roteador ativo e um roteador standby são eleitos
- Hosts na rede são configurados para usar o endereço virtual como gateway.
- O roteador ativo responde requisições ARP usando o MAC virtual, o tráfego destinado para outras redes será enviado para ele.
- Se o roteador ativo cair, o roteador standby se torna o novo ativo.
- O novo roteador ativo irá enviar mensagens ARP para que os switches atualizem suas tabelas de endereço MAC, ele então funcionará como gateway.
- Se o antigo roteador ativo retornar, por padrão ele não irá voltar á sua função original como roteador ativo. Ele se tornará o standby
- Você pode configurar 'preemption', então o roteador retornará a sua função original.
