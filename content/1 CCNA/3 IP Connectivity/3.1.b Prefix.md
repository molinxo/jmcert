É a rede de destino de uma rota específica, normalmente é o endereço de rede com a máscara de rede (ex. 192.168.2.0/24)

É usado para apontar para onde o tráfego deve ser encaminhado, roteadores usam o prefixo na tabela de roteamento que corresponde com o destino no pacote para escolher a melhor rota.

Se o endereço de IP de destino do pacote corresponder com o range do prefixo na tabela de roteamento, então o roteador já sabe a rota ou próximo salto que irá enviar o pacote.
