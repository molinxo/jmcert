Métrica é o custo para alcançar um destino específico. Roteadores usam a métrica para escolher o melhor caminho quando existem múltiplas rotas para o mesmo destino.

Cada protocolo de roteamento possui a sua própria métrica e calcula o 'custo' de forma diferente.

Métricas existem para caso diferentes rotas para o mesmo destino possuam a mesma distância administrativa. a me
