Distância administrativa ou AD é um parâmetro usado pelo roteador para conferir a confiabilidade de um protocolo de roteamento quando existem múltiplas rotas aprendidas com diferentes protocolos para um mesmo destino.

Se existir múltiplas rotas para o mesmo destino aprendidas por origens diferentes. O roteador irá utilizar aquela com a MENOR distância administrativa.

| Origem da rota        | AD padrão |
| --------------------- | --------- |
| Diretamente conectada | 0         |
| Rota estática         | 1         |
| External BGP          | 20        |
| Internal EIGRP        | 90        |
| OSPF                  | 110       |
| IS-IS                 | 115       |
| RIP                   | 120       |
| External EIGRP        | 170       |
| Desconhecida          | 255       |
