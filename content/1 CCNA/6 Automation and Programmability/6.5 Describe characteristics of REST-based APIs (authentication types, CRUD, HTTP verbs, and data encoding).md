### Tipos de autenticação:

- Basic Authentication
  - login e senha
  - enviados no header HTTP
- Token-based Authentication
  - Usa tokens de acesso
  - Mais seguro.
- API keys
  - Chave única usada em aplicações
### CRUD
CRUD representa as quatro operações básicas sobre dados:

| Operação | Função          |
| -------- | --------------- |
| Create   | criar dados     |
| Read     | consultar dados |
| Update   | atualizar dados |
| Delete   | remover dados   |

### HTTP Verbs
As APIs REST usam métodos HTTP para realizar operações CRUD.

| HTTP Verb | Função            | CRUD   |
| --------- | ----------------- | ------ |
| GET       | obter informações | Read   |
| POST      | criar recurso     | Create |
| PUT       | atualizar recurso | Update |
| DELETE    | remover recurso   | Delete |

Exemplo:

```
GET /devices
```

Retorna lista de dispositivos.

### Data Encoding

As APIs trocam informações em formatos estruturados.

Os mais comuns:

- JSON
  - leve e mais usado atualmente.

Exemplo:

```
{  "hostname": "R1",  "ip": "192.168.1.1"}
```

- XML
  - mais antigo;
  - ainda usado em algumas aplicações de rede.
### Características do REST
- usa HTTP/HTTPS;
- comunicação cliente-servidor;
- normalmente stateless (sem manter sessão);
- recursos identificados por URLs.
