Componentes principais:

- Objetos
```
{  "hostname": "R1"}
```

- Pares chave : valor
```
"hostname": "R1"
```

- Arrays (listas)
```
{  "vlans": [10,20,30]}
```

- Tipos de dados
  - string → `"R1"`
  - número → `10`
  - boolean → `true`
  - null → `null`

Resumo:
- JSON organiza dados em **chaves e valores**.
- Usa `{}` para objetos e `[]` para listas.
- Muito usado em REST APIs e automação.
