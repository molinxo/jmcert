Northbound and southbound API's referem-se a termos de abstração da arquitetura de redes SDN que também pode ser chamada de Software-Defined Architecture ou Controller-Based Networking.

Software-Defined Networking (SDN) é uma forma de construir a rede que centraliza o control-plane em uma aplicação chamada Controller

Um controller SDN centraliza as funções do control plane como calculo de rotas e outros.

A controladora consegue interagir de forma programável com a rede utilizando API's (Application Programming Interface)

### Southbound APIs
- SBI é usada para comunicações entre a controladora e os equipamentos de redes que ela controla.
- Normalmente consiste na comunicação de um protocol e uma API
- API's facilitam a troca de dados entre programas
  - Dados são trocados entre a controladora e os equipamentos de rede
  - Uma API nos equipamentos de rede permite que a controladora acesse informações dos devices, controle seu data plane, tabelas de dados e etc..
- Alguns exemplos de SBIs:
  - OpenFlow
  - Cisco OpFlex
  - Cisco onePK
  - NETCONF

### Northbound APIs
- A NBI é o que permite que nós interajamos com a controladora, acesse os dados que reúne sobre a rede, á programe e faça diferenças na rede via SBI
- Uma REST API é usada na controladora como interface para que aplicativos interajam com ela
- Dados são enviados num formato estruturado (serializado) como JSON ou XML

## CISCO DNA CENTER

DNA é uma sigla para digital network architecture. o CISCO DNA permite que você envie operações e facilite o gerenciamento da rede por meio de automações e monitoria controlados por uma interface gráfica.

O DNA center permite que qualquer rede em qualquer lugar seja controlada remotamente por meio da interface de qualquer lugar do mundo, via cloud.

O CISCO DNA roda como sistema baseado em linux no hardware Cisco UCS (Servidor)

IBN Intent Based Networking
IBN transforma uma rede tradicional em uma rede por controller que transforma as necessidades da rede em políticas que podem ser aplicadas consistentemente via rede. O intuito é continuamente monitorar e ajustar a performance dependendo da necessidade.

Diferenças da rede tradicional / IBN
- Uma rede tradicional depende de configurações específicas para cada modelo de equipamento o que pode fazer com que o setup da rede demore semanas ou meses, além de aumentar a chance de erros humanos.
- Na rede IBN é possível que configurações que demorariam dias possam ser alteradas com alguns botões na interface(ex. coisas como separação das redes ou políticas de acesso).

A interface do CISCO DNA Center conta com funções principais sendo essas:
- Design
- Policy
- Provision
- Assurance
Além de contar com funções de plug n' play (via DHCP ou DNS) e descobrimento de equipamentos.
