- Anycast é um para um de muitos
- Múltiplos roteadores são configurados com o mesmo IPv6
	- Eles usam o protocolo de roteamento para anunciar o endereço
	- Quando hosts enviam pacotes para aquele endereço destino, roteadores irão enviar para o roteador mais próximo configurado com aquele endereço IP.
	- Não há um range específico de endereço para o anycast. Use o endereço unicast padrão (global, unicast, unique) and especifique como um endereço anycast

```
R1(conf-if)# ipv6 address                  anycast
```
