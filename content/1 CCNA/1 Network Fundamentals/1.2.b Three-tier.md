Em uma Rede LAN grande com vários Switches de distribuição, o número de conexões necessárias entre os Switches cresce rapidamente. Para ajudar a escalar uma rede LAN é possível adicionar uma camada "Core" (Core Layer) 

A cisco recomenda adicionar essa camada se existem mais de três switches de distribuição na rede.

A topologia "Three-Tier" consiste em três grupos hierárquico de equipamentos de redes de computadores chamados de camadas ou Layers, uma Camada de Acesso (Access Layer) e uma Camada de Distribuição (Distribution Layer) e uma camada Core (Core Layer).

### Layer de acesso
- End hosts (PC's, cameras, servidores, etc..) serão conectados nessa camada
- Normalmente os switches de acesso possuem muitas interfaces para comportar end hosts
- QoS normalmente é configurado nessa camada
- Segurança baseada nas interfaces é configurada nessa camada
- É necessário que o switch tenha PoE para conectar AP's e telefones por IP

### Layer de distribuição
- Une as conexões dos switches de acessos da Camada de acesso

### Layer de Core
- Conecta e une camadas de distribuição em uma rede LAN 
- O foco é a velocidade ('Fast transport')
- Operações que usam muito CPU como QoS e configurações de segurança devem ser evitadas nessa camada
- Conexões são no Layer 3. Nada de Spanning Tree!
- Deve suportar a conectividade pela LAN mesmo se um device falhar.
