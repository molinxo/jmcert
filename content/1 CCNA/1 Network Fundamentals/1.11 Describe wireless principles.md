A comunicação Wirelless se propaga pelo espaço usando frequência de rádio (RF) onde um device (transmitter) envia o sinal para outro device (receiver). Os dois devices devem usar a mesma frequência ou canal para se comunicarem. 

Frequências de rádio podem causar intereferencia quando muitos aparelhos wireless se comunicam ao mesmo tempo. Quanto mais aparelhos, maior a interferência.

### 802.11 Standards

| Standard | Frequencies    | Max Date Rate | Alternate name |
| -------- | -------------- | ------------- | -------------- |
| 802.11   | 2.4GHz         | 2 Mbps        |                |
| 802.11b  | 2.4GHz         | 11 Mbps       |                |
| 802.11a  | 5GHz           | 54 Mbps       |                |
| 802.11g  | 2.4GHz         | 54 Mbps       |                |
| 802.11n  | 2.4GHz / 5GHz  | 600 Mbps      | 'Wi-Fi 4'      |
| 802.11ac | 5GHz           | 6.93 Gbps     | 'Wi-Fi 5'      |
| 802.11ax | 2.4 / 5 / 6GHz | 4* Gbps       | 'Wi-Fi 6'      |
