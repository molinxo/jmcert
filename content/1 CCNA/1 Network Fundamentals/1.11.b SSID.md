Service Set Identifier (SSID) é o nome da rede Wi-Fi. O SSID é um ID único de 32 carácteres utilizado para identificar redes wireless.

SSIDs confirmam que dados serão roteados para o ponto específico quando houver múltiplas redes wireless coexistindo na mesma área. A rede é conectada á um endereço MAC na AP.

O SSID é o que seus clientes usam para conectarem á rede. Portanto, o SSID na AP é uma junção do endereço MAC e o nome da rede. Esse endereço MAC pode ser um endereço diferente criado pela AP.

Basic Service Set Identifier (BSSID) descreve uma AP que funciona em apenas uma rede.

A opção de usar múltiplos SSIDs é garantida pela AP. isso garantirá a possibilidade de usar a mesma AP providenciando uma rede de convidados e uma rede corporativa.

Multiple Basic Service Set Identifiers (MBSSID) são usados quando uma AP possui múltiplas redes. Apesar de providenciar redes diferentes, ainda é o mesmo hardware.

Usuários de redes diferentes compartilham a rede porque o hardware e a frequência ainda é a mesma, se eles se comunicarem ao mesmo tempo pode haver um conflito.
