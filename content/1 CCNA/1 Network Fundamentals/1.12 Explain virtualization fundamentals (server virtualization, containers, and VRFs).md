Virtualização é o processo de operar um computador virtual. O software usado na virtualização permite executar sistemas, hardware e aplicativos virtuais em uma única máquina. Frequentemente, é utilizada para executar diversos sistemas operacionais, incluindo Windows e Linux, em um único dispositivo.

Para aproveitar ao máximo o hardware, a virtualização permite dividir sistemas grandes em vários menores. Pense em servidores, por exemplo. O uso da virtualização permite dividir um único servidor para várias finalidades, em vez de usar vários servidores para executar atividades distintas. Como resultado, um dos servidores pode ser dividido para gerenciar tanto e-mails quanto aplicativos, em vez de ter servidores para rede, e-mail e aplicativos que não estão sendo usados ​​em todo o seu potencial.

A eficiência do servidor é maximizada dessa forma. Ao utilizar o hardware do servidor, como o processador, a RAM e a memória de armazenamento, a virtualização pode transformar um único servidor físico em vários PCs virtuais (máquinas virtuais) que funcionam como computadores digitais. Cada máquina virtual opera de forma independente, assim como um computador real. Portanto, a virtualização é a maneira ideal de utilizar uma única máquina.

Grandes centros de dados que fornecem hospedagem de sites ao público utilizam computação em nuvem. A base da computação em nuvem é a virtualização completa dos servidores. Um grande centro de dados utiliza um único servidor de alta capacidade para hospedar diversos sites que podem ser acessados ​​de qualquer endereço IP público e exigem diferentes formas de autenticação. O usuário paga apenas pelos serviços que realmente precisa. Se um site requer apenas 10 GB de espaço para hospedagem, o cliente paga ao provedor de serviços somente por esses 10 GB. Ele não precisa pagar por toda a configuração de memória SAN (Storage Area Network) ou NAS (Network Attached Storage) . A virtualização do hardware do computador é a única responsável por isso. Máquinas virtuais podem incluir computadores, servidores, roteadores, firewalls , etc. É possível criar uma máquina virtual em um servidor físico e inserir máquinas virtuais menores dentro dela, de acordo com as necessidades.

### Componentes-chave da virtualização:
- **Host machine:** o primeiro elemento de uma estrutura de rede virtual é o host. o hardware físico no qual as máquinas virtuais são executadas. Ela inclui componentes como CPU, memórias e armazenamento. 

- **Virtual machine:** As máquinas virtuais compõem a parte restante da estrutura de rede virtual. o objeto virtual que existe no host é chamado de máquina virtual, Ela replica virtualmente o dispositivo físico. Cada dispositivo virtual acredita ser o único no sistema.

- **Hypervisor:** o hypervisor é o elemento final em uma estrutura de rede virtual. O componente essencial da virtualização é o hypervisor, também conhecido como Virtual Machine Management. Em essência o hypervisor é um software usado para construir e supervisionar computadores virtuais em um host. A principal função do hypervisor é controlar os dispositivos virtuais e fornecer a eles os recursos de sistema apropriados.
	- **Type 1 Hypervisor (Bare-metal Hypervisor)**: Refere-se á um software instalado e opera diretamente encima do hardware do host. Eles rodam em sistemas operacionais separados. Devices usados em data centers comumente usam esse tipo de hypervisor. Os benefícios são melhor performance, escalabilidade e disponibilidade já que eles acessam diretamente os recursos do host.
	  
	  Exemplos: VMware ESXi e Hyper-V
	- **Type 2 Hypervisor Hosted Hypervisors):** Ao contrário do Tipo 1, que opera diretamente no hardware, os hypervisor Tipo 2, também conhecidos como hosted-hypervisors, são executados em sistemas operacionais instalados no hardware. Cada Máquina Virtual opera no hypervisor desse sistema. Vários sistemas operacionais podem ser executados simultaneamente em hardware físico usando esse tipo de hypervisor. Há apenas um sistema operacional, e é nele que o hypervisor se encontra. Também podemos instalar outros sistemas operacionais sobre ele. Um programa de console de gerenciamento não é necessário para o Type 2 Hypervisor (Hosted Hypervisor). Essa vantagem é significativa e, consequentemente, aumenta a popularidade desse tipo de hypervisor.
	  
	  Exemplos: VMware Fusion, VirtualBox, Virtual PC, Mac OS X Parallels e VMware Workstation

### Funcionamento

Os hipervisores, programas de computador que dividem os recursos reais para que as máquinas virtuais possam utilizá-los, são a base do processo. Existem dois tipos de hipervisores: os hipervisores "bare metal", que operam como um sistema operacional, executando as máquinas virtuais dos convidados no hardware de um sistema, e os hipervisores "hospedados", que se comportam mais como programas comuns que podem ser iniciados e interrompidos conforme necessário

### Tipos de virtualização

- **Virtualização de dados:** A virtualização de dados combina dados de diversas fontes e os torna acessíveis a qualquer aplicação, independentemente da origem, localização ou formato. Entre as aplicações que acessam os dados e os sistemas que os armazenam, é construída uma camada de software. Essa camada, então, aceita uma solicitação de dados de uma aplicação e retorna resultados que podem vir de sistemas diferentes.

- **Virtualização de Aplicativos:** Você pode executar software usando virtualização de aplicativos sem precisar instalá-lo no seu sistema operacional. Por exemplo, você pode usar isso para executar um aplicativo Windows no Linux. Isso pode ser feito usando um servidor, streaming de aplicativos ou executando o aplicativo completo localmente no dispositivo do cliente, em um ambiente de execução, em vez de no hardware nativo. Um servidor executa o aplicativo por completo e fornece a interface do usuário para o dispositivo do cliente.

- **Virtualização de rede:** Utilizando a virtualização de rede, os servidores recebem instantaneamente componentes e recursos de rede específicos, como configuração de IP e compartilhamento de arquivos. Como resultado, os administradores de rede podem alterar e gerenciar esses componentes sem afetar os componentes físicos.

- **Virtualização de desktops:** Isso permite executar vários sistemas operacionais na mesma máquina. Isso pode ser feito usando virtualização de desktop local ou Virtual Desktop Infrastructure (VDI), que executa um hipervisor em um computador local e permite executar um sistema operacional adicional nesse computador. A VDI executa vários desktops em um servidor central e os transmite para os usuários que fazem login em dispositivos clientes.

- **Virtualização de armazenamento:** Todos os dispositivos de armazenamento em uma rede, incluindo os independentes e os instalados em servidores individuais, podem ser acessados ​​e gerenciados como um único dispositivo de armazenamento graças à virtualização de armazenamento. Eles podem ser realocados para qualquer máquina virtual na rede, conforme necessário, armazenando-os em um pool comum.

## Benefícios da virtualização:

- Utilização perfeita dos recursos ou hardware disponíveis.
- O processo de instalação de várias máquinas leva menos tempo.
- Para oferecer uma variedade de serviços, o tempo de inatividade pode ser reduzido.
- Gestão centralizada e manutenção simples. 
- Reduzir despesas 
- Aumentar a eficácia e preservar o espaço do servidor.
- Segurança
- Isso facilita a reversão de ataques de vírus, ao contrário dos sistemas tradicionais. Se necessário, o computador virtual pode até ser recriado ou removido.
