- Endereços multicast são um para muitos
	- Um source, múltiplos destinos.
- IPv6 usa o range FF00::/8
- IPv6 não usa broadcast.
- IPv6 define múltiplos escopos multicast que indicam quão longe o pacote deve ser enviado
- O escopo IPv6 multicast
	- Interface-local (FF01): o pacote não sai o device local. Pode ser usado para enviar tráfego para o serviço entre o device local.
		- Link local (FF02): O pacote continua na sub-rede local
		- Site local (FF05): O pacote pode ser enviado por roteadores. Deve ser limitado a apenas uma localização física (Não usar na WAN)
		- Organization local (FF08): Escopo aumentado
		- Global (FF0E): Sem limites, pode ser roteado pela internet.
