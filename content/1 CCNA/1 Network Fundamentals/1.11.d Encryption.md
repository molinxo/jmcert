Por definição encriptação é um algoritmo para os dados para que mude como ele se parece e se apresenta para confundir outros sem acesso.

Datagram Transport Layer Security (DTLS) mantém pacotes seguros quando a criptografia de dados é habilitada na AP.

Vários mecanismos de autenticação são usados durante o procedimento de identificação.

Features de segurança como autenticação de quadros e encriptação são usados para proteger o dado wireless. 

O dado precisa ser criptografado na rede wireless para garantir a privacidade do pacote. Isso é alcançado encriptando o conteúdo dos dados em cada frame wireless antes da transmissão e descriptografar após a recepção.

O objetivo é criptografar e descriptografar os dados com sucesso, empregando uma técnica de criptografia que tanto o transmissor quanto o receptor possam usar.

Todos os clientes devem associar-se usando o mesmo método de criptografia porque cada WLAN em redes sem fio pode permitir apenas uma metodologia de autenticação e criptografia.

Para que o AP e o cliente interpretem os dados um do outro, eles devem ser os únicos dois dispositivos que compartilham as chaves de criptografia. Nenhum dispositivo deve estar ciente das chaves ou ser capaz de usá-las para interceptar e decodificar os dados.
