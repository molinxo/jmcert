TCP e UDP são protocolos da camada de acesso que possuem diferentes características que definem quais serão os usos práticos para as aplicações posteriormente nas camadas seguites do modelo OSI.

### Transmission Control Protocol (TCP)
O TCP é um protocolo de transporte confiável e orientado à conexão que garante a entrega de dados precisa e ordenada. Utiliza mecanismos de controle para garantir a exatidão dos dados, o que o torna mais lento, mas confiável.

- Protocolo orientado a conexão
- Entrega de dados confiável e ordenada
- Maior sobrecarga, mas alta precisão

### User Datagram Protocol (UDP)
O UDP é um protocolo de transporte rápido e sem conexão que envia dados sem garantias de confiabilidade. É eficiente para aplicações onde a velocidade é mais importante que a precisão.

- Sem conexão e leve
- Nenhuma garantia de entrega ou pedido
- Baixa sobrecarga e alta velocidade

---

| TCP (Transmission Control Protocol)             | UDP (User Datagram Protocol)           |
| ----------------------------------------------- | -------------------------------------- |
| Connection-oriented; uses a three-way handshake | Connectionless; no handshake           |
| Guarantees reliable data delivery               | Does not guarantee delivery            |
| Uses acknowledgements (ACKs)                    | No acknowledgements                    |
| Supports retransmission of lost packets         | No retransmission support              |
| Ensures packets are delivered in order          | Does not ensure ordering               |
| Provides flow control and congestion control    | No flow or congestion control          |
| Slower due to higher overhead                   | Faster with minimal overhead           |
| Variable header size (20–60 bytes)              | Fixed header size (8 bytes)            |
| Treats data as a continuous byte stream         | Treats data as independent messages    |
| Does not support broadcasting or multicasting   | Supports broadcasting and multicasting |
| Used by HTTP, HTTPS, FTP, SMTP                  | Used by DNS, DHCP, VoIP, Streaming     |
