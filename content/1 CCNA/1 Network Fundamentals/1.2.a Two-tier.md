A topologia "Two tier" consiste em dois grupos hierárquico de equipamentos de redes de computadores chamados de camadas uma Camada de Acesso (Access Layer) e uma Camada de Distribuição (Distribution Layer).

### Layer de acesso
- End hosts (PC's, cameras, servidores, etc..) serão conectados nessa camada
- Normalmente os switches de acesso possuem muitas interfaces para comportar end hosts
- QoS normalmente é configurado nessa camada
- Segurança baseada nas interfaces é configurada nessa camada
- É necessário que o switch tenha PoE para conectar AP's e telefones por IP

### Layer de distribuição
- Une as conexões dos switches de acessos da Camada de acesso
- Conecta á serviços como Internet, WAN, etc..
