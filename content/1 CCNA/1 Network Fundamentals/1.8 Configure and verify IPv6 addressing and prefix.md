O IPv6 é a versão atualizada do protocolo IP. O IPv6 foi desenvolvido pra resolver algumas deficiências do IPv4, como o problema de exaustão de endereços.

Em comparação com o IPv4 que possui apenas 4.3 bilhão de combinações de endereços disponíveis, o IPv6 permite 3.4 x 10^38

##### Características do IPv6
- Endereços maiores: o IPv6 usa endereços 128-bit, garantindo um range maior de possíveis endereços.
- Segurança aumentada: IPSec é integrado ao IPv6 como parte do protocolo.
- Melhoria nos headers: O pacote header usado no IPv6 é simples comparado ao usado no IPv4. O header do IPv6 não é protegido por um checksum, então roteadores não calculam o checksum para cada pacote.
- Não dependente de NAT: desde que todos os devices tenham um IPv6 único, não haverá necessidade para NAT
- Stateless address autoconfiguration: aparelhos IPv6 podem se auto-configurar com um endereço IPv6

## Configuração

Enable global:

```ipv6 unicast-routing```

Atribuição IPv6:
```ipv6 address address/eui-64```

Exemplo atribuição:
```
R1(config)#ipv6 unicast-routing
R1(config)#int Gi0/0
R1(config-if)#ipv6 address 2001:0BB9:AABB:1234::/64 eui-64
```

Verificação:
```show ipv6 interface Gi0/0```
