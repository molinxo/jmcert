### O que é um Switch de rede? 
Um switch é um hardware que conecta múltiplos devices em uma ou várias redes LAN e usa o endereço MAC para encaminhar pacotes para um destino específico. Ele opera inspecionando pacotes que chegam e decidindo onde enviá-los.

### Switch Layer 2
Switches de layer 2 operam na camada de Data Link Layer (Layer 2) do Modelo OSI e usa o endereço MAC para encaminhar data frames

- Aprendizado e encaminhamento de endereço MAC
- Possibilidade de segmentação VLAN
- SEM capacidade de Roteamento

### Switch Layer 3
Switches de layer 3 combinam a funcionalidade de um switch e um router. eles operam tanto na camada de Data Link Layer(Layer 2) quanto na camada Network(Layer 3), possibilitando roteado via VLAN.

- Roteamento IP entre VLAN's
- Conta com protocolos avançados de roteamento como OSPF e RIP.
- Oferece alta performance para o tráfego entre VLAN's
