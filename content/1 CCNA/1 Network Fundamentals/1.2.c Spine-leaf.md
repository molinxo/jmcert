Essa arquitetura foi desenhada para Data Centers

Essa arquitetura funcionava melhor quando o tráfego no data-center era Norte-Sul.

Com o crescimento da virtualização de servidores, aplicações são comumente deployadas de forma distribuída, o que aumenta a quantidade de tráfego Leste-Oeste no data-center.

 A arquitetura 'Three-Tier' tradicional leva a gargalos tanto na largura de banda quanto na variação de latência entre servidores dependendo do caminho que o tráfego escolhe. Para resolver isso a arquitetura Spine-Leaf se tornou proeminente em data-centers.

### Regras na arquitetura Spine-Leaf
- Todos os Leaf switches se conectam em todos os Spine switches
- Todos os Spine switches se conectam em todos os Leaf switches
- Leaf switches não se conectam a outros Leaf switches
- Spine switches não se conectam a outros Spine switches
- End hosts apenas se conectam a Leaf switches.

O Caminho que o tráfego percorre é escolhido aleatoriamente  para balancear o tráfego entre os Spine switches.

Todos os servidores são separados pelo mesmo número de saltos (a excessão são os servidores conectados no mesmo switch de acesso), providenciando a mesma latência entre todos os servidores.
