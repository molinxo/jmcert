### Global unicast
- São os endereços públicos que podem ser usados pela Internet.
- Necessário registrá-los para uso. Já que eles são públicos é esperado que sejam únicos.
- Originalmente definido no bloco 2000:: /3.
- Atualmente definidos como qualquer endereço que não haja um propósito definido.

	==2001:0DB8:8B00==:0001==::==/64
	==2001:0DB8:8B00== :0001 ==::== /64

- 48-bit prefixo de roteamento global atribuído pela provedora.
- 16-bit identificador da sub-rede
- 64-bit identificador da interface, a porção de host do endereço 

### Unique Local IPv6
- São endereços privados que não podem acessar a internet.
- Não é necessário registrá-los para usar.
- Eles podem ser usados livremente dentro da rede internet e não precisam ser únicos globalmente.
- Não podem ser roteados para a internet.
- Usam o bloco FC00::/7
- Após uma atualização foi necessário set 1 no oitavo bit, então os dois primeiros dígitos são FD
- O ID global deve ser único para que não ocorra overlap quando a rede aumentar.

	==FD==45:93AC:8A8F:==0001::==/64
	==FD== 45:93AC:8A8F: ==0001::==/64

- Indicação de Unique Local IPv6
- 40-bit Global ID que deve ser gerado aleatoriamente
- 16-bit Identificador de sub-rede.

### Link-local IPv6
- São gerados automáticamente na interface habilitada com IPv6
- Use o comando R1(conf-if)#ipv6 enable
  on an interface to enable IPv6
- Usa o bloco FE80::/10
- Entretanto, o padrão define que o bit 54 após FE80:/10 devem ser todos 0, então você nunca irá encontrar endereços começando em FE9,FEA,FEB apenas ==FE8==
- O id da interface é gerado usando EUI-64
- Link-local significa que os endereços serão usados para comunicação entre um único link. Roteadores não irão rotear pacotes para um destino link-local.
- Usos comum do link local:
	- Protocolos de roteamento para peering.
	- Endereços next-hop para rota estática.
	- Neighbor Discovery Protocol
