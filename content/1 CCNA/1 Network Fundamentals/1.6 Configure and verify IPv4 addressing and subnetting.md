### IPv4
- Fornece conexão aos dispositivos
- Fornece endereçamento lógico
- Fornece seleção de caminho
- Roteadores operam na camada 3

O endereço IPv4 opera da seguinte maneira, são 4 grupos de 8 bits totalizando 32 bits.
Os 32 bits são separados em dois grupos indicados pela máscara, a porção de rede e a porção de hosts.

%%Exemplo%%

| Classe | Primeiro Octeto | Range numérico do primeiro octeto |
| ------ | --------------- | --------------------------------- |
| A      | 0xxxxxx         | 0-127                             |
| B      | 10xxxxxx        | 128-191                           |
| C      | 110xxxxx        | 192-223                           |
| D      | 1110xxxx        | 224-239                           |
| E      | 1111xxxx        | 240-255                           |

### Subnetting
Pegar 1 bit pode criar 2 subnets

formula
2^x
x = número de bits "emprestados"

#### Subnets/Hosts

| Prefix | Subnets | Hosts |
| ------ | ------- | ----- |
| /25    | 2       | 126   |
| /26    | 4       | 62    |
| /27    | 8       | 30    |
| /28    | 16      | 14    |
| /29    | 32      | 6     |
| /30    | 64      | 2     |
| /31    | 128     | 0(2)  |
| 32     | 256     | 0(1)  |
Para cada bit emprestado, o número de sub-redes dobra.
Para cada host bit o número de hosts dobra.

#### VLSM - Variable Length Subnet Masking

1) Atribua a maior sub-rede no começo do espaço de endereçamento.
2) Atribua a segunda maior sub-rede depois.
3) Repita o processo até todas as sub-redes serem atribuídas

no shutdown
